# 地图与电脑设计

更新：2026-09-12。v1.6 保留六图 42 个节点，增加相邻道路与较慢节奏。地图关系和电脑启发式已进入本地实现；体验与系统性平衡仍需实测，不以规则测试代替通关、乐趣或真机结论。基础属性/时空/胜负见[主文档](01-产品与玩法设计.md)，奖励见[D](03-策略与军衔设计.md)，未来体验检验见[F](07-平衡与测试计划.md)。

## A1. 布局约束

战场 360×540，左上原点。中心 X40 至 320、Y55 至 485，两城中心至少 64 逻辑单位。逻辑路径半径 18，实际触控不少于 44 屏幕逻辑像素；画面缩放不改变距离。

P=玩家，E=教学电脑，E1/E2/E3=四方互为敌人的电脑，N=中立。初始生产额度 0、效果空。地图初始等级为 1／2，局内可升至 3；首发类型为 barracks／archery／relay／fort，对应步兵营／弓营／骑营／塔营。生产与箭塔初始节拍按主文档初始化，不能用旧类型参数。所有参赛阵营至少一城，初始驻军不超基础容量，ID 全局唯一。

v1.6 新局采用无向道路：只允许相邻城市派兵，友援也不能越城；三张正式图的每座出生城提供两条外环出口，外环连接可绕过中央，中央四向连接提供调兵优势和多面防守压力。道路必须可见，不增加隐形地形碰撞。节点 ID、坐标、初始兵力、类型与下表保持。

v1.5 存量对局保持任意直达和旧节奏，正常结算后下一局切换新规则；不自动迁移正在行军的路线。

新局电脑首动 8000 ms，三方分别错开 0／700／1400 ms，之后各间隔 3500 ms。攻击、救援、转运均需邻接；威胁预测覆盖 8 秒，后方兵力沿己方道路送往前线。不得通过更快输入或凭空资源制造难度。v1.5 的旧节奏仅用于存量对局恢复，见 A6 兼容说明。

道路美术以不规则土边、压实路心与双车辙组成，同一真实路段采用稳定的带状边缘，部队中心线仍为原直线。三种地表分别使用暖土、冷灰和砂石配色；所有六图共用，选源时仅高亮真实出口。城外院落采用轻薄踩踏土斑，中央石坪保持明确。边缘起伏不改变节点、邻接、道路旅时、塔射或 v1.5 直达恢复；跨路仍显示不可达原因，不画表外岔路。

首次教学：

验证至少包括：占中立再扩张、过早攻击的后果、失败重试、停留教学 30 秒不改变初始局势。

### A6.1 可见信息与合法来源

电脑可读当前公开据点属性、兵力和已出发兵团的目标/到达时间；这些信息须由数字、行军和交互查询向玩家表达。不能读取尚未松手的目标或未来输入。

- 按 ID 升序枚举己方据点，以同一派兵函数计算 S；攻击和友援目标都必须与来源有道路直接相连。
- 派出后至少保留 max(4, ceil(容量 × 0.10)) 兵；这是电脑偏好，不限制玩家。
- 普通攻击还需达到表中最低驻军。紧急增援可跳过最低驻军，但不能跳过保留要求。
- 若来源自己在观察窗口内有预计扛不住的攻击，则不从它出兵。
- 一次决策只选一个动作，执行后等下一时刻重新观察。

### A6.2 优先级一：增援受威胁据点

对每个己方城检查未来 8 秒内已知敌军的到达和待齐射时刻 T：

- 在复制状态中按真实规则推进生产、到达、塔射和齐射；首次出现本城易主或驻军清零即记为威胁。
- 清零齐射仍保留归属时，也保留其后实际易主时刻作为救援机会；不能因为拦不住先前齐射就放弃及时到达的援军。
- 威胁按更早时刻、目标 ID 排序；所有已占领城都计存活，不另造主城特权。
- 从与受威胁城相邻、能在 T 前或同刻抵达、满足保留条件的己方来源增援，优先更短行军时间，再优先更多 S，再按来源 ID。
- 只有完整预测能使本城在 T 时仍为己方且留有兵力，才派出该援军；没有及时援军就进入下一优先级，不能传送、延迟敌军或免费补兵。

预测是公开信息启发式，不是结果保证。不生成未知玩家／电脑未来指令。仅在无射击、无更早交战及无余量／容量边界时，才能用“当前驻军＋生产＋已知增援”的简式估算；实际候选统一调用事件预测。塔下在途损失会降低齐射伤害，友方／空营跳过也按真实规则处理。

观察窗口内既检查敌队到达，也检查已知齐射是否会削弱守军、停止塔营开火或改变随后守城结果；公开可见的齐射状态／时刻可供双方查询。可及时到达的增援按完整预测评价，不把“挡不住齐射扣数”误当成“不能守城”。不赋予电脑驻营反射、途中冲撞或读取未提交输入的能力，真实结算仍调用共同规则。

### A6.3 优先级二：扩张或进攻

对合法来源与道路相邻的非己方目标组合：

1. 按源营兵种计算派兵 S 与行军时间 T，将候选队连同其齐射检查加入预测副本，按公共时间线估算沿途塔射、齐射和实际到达。
2. D 取预测副本在该候选到达交战前的实际守军（含同刻守方增援），A 取本队剩余人数；齐射已在其检查时刻扣过，不再把 30%加进 A 或重复扣 D。无射击／更早交战时才可使用“当前驻军＋生产＋已知增援”的简式。
3. 在不加入本候选队的预测副本中，若已出发本方部队能更早占领、到 T 时仍持有且留足安全余量，则暂不重复攻击，等待新状态；不把原始在途兵数与已扣过齐射的 D 机械比较。
4. 普通攻击要求预测由本阵营占领且最终留兵至少达到安全余量；多方同刻用主文档合并裁决，不把齐射清零或同量抵消误认成夺城。
5. 单源不够时，v1.6 可以评估两源协同：第一队现在出发，在真实推进 3500 ms 后，从另一个仍归己方、达最低兵数且也与目标相邻的来源再派半数。第二队按普通速度、不预支兼行；推进至两队都到达后，最终仍须占领且留足余量。当前决策只提交第一队；下一次重新观察，不预扣第二队或保证未来命令必定执行。
6. 两源也不足时，只允许有条件的消耗进攻：目标为有主敌城，本方城数多于该敌方；前线来源至少有容量 80% 的驻军，另有与来源相邻、符合安全来源条件且至少半容量的己城作为后方支持；预测削减守军数至少达到本次派兵的 80%。不满足则等待。此分支可暂不夺城，不对中立使用，也不凭空增加后方兵力。
7. 评分 = 100×是否中立 + 120×是否目标阵营最后据点 + 20×目标按己方属性计算的自然产速 − 8×T 秒 − 0.25×D − 分支扣分。D 是未加入该候选的预测副本在 T 时的驻军；普通攻占不扣分，两源协同扣 30，后方支持的消耗进攻扣 150。
8. 高分优先，同分按更短 T、目标 ID、来源 ID 依次决定。协同与消耗都使用公开状态，不模拟未知的未来玩家操作。

目标在路上增援会让电脑攻击失败，允许这种结果，不读档纠正。评分不增加伤害或奖励。

### A6.4 优先级三：安全升级，然后调动后方储备

没有紧急增援或可行攻击时，先找安全升级：驻军达门槛、未来 8 秒公开预测无敌队到达、敌塔伤害或弓兵齐射伤害、扣费后至少留 10 人；优先升级后自然产能提升更大的营地，再按 ID。升级一次即结束此次决策；不满足则检查后方调兵：

- 来源至少达到容量 50%，仍满足安全来源和保留兵力要求。
- 目标是相邻己城。只沿己方城市扩展道路，计算到最近非己方城市（包括中立）的道路步数；目标至少比来源减少一步。实现中每步记 100 分，改善须不少于 40 分；该分数不是欧氏距离。
- 目标驻军 + 已知在途友军 + 本次 S 不超容量，避免主动浪费。
- 优先距离改善最大，再按行军时间、目标 ID、来源 ID；没有候选就等待。

两源协同、后方支持与拒绝孤立亏损出兵的自动边界见 [tactical-rules.test.ts](../tests/tactical-rules.test.ts)：包括缺少第二来源、3500 ms 内防守生产导致边际协同失败、后方不足时拒绝消耗。它们验证决策与真实结算，不证明所有地图都能被玩家通关或已经平衡。实际关卡长期僵持时仍应重测，不临时给电脑隐形属性。


## A7. 正式四方标准电脑

三个电脑首次决策分别为 8.0／8.7／9.4 游戏秒，之后各隔 3.5 秒、进攻最低驻军 12、安全余量 2、防守窗口 8 秒，基础决策同 A6。对所有非己方阵营同样评分，没有 P 专属仇恨值。各自征召乡勇 1 张、无其他主动、被动 0 层，战前公开。

同刻从同一公开快照选择，每个电脑最多一个动作，提交再校验。防守预测允许保守合计敌军，实际交战仍用多阵营抵消，不准为电脑换伤害公式。阵营 ID 可以稳定启发式选目标，不能打破名次并列。

### A7.1 库存驱动的卡片优先级

1. 征召乡勇：8 秒内受袭且补最多 6 兵能避免预计被占领时使用，按最早威胁时刻／目标 ID。有库存时下次可再补。
2. 测试显式提供火袭粮营时：己方来兵 8 秒内到达，且对该敌方目的营地停产／停射后，预测可占领，且比不用卡更有利时使用；续时须仍对本次行动有用。
3. 执行 A6 的增援／扩张／安全升级／调兵；测试提供倍道兼行时，仅在能缩短 ETA 时使用，否则普通出兵不浪费卡。
4. 测试提供鸣鼓征兵时：无更高优先动作，未来 8 秒安全、空缺至少 8，优先高产速/ID；已有鸣鼓征兵剩余超过 2 秒时倾向节约。
5. 无有效动作等待。不得免费补兵、刷新库存、读玩家手势或偷改产速。

标准配置只有征召乡勇 1 张，但给测试电脑 3 张必须支持三次合法决策各用一张。AI 间隔是行为节奏，不建立玩家共享冷却。跨周旧未用电脑主动同样到期，不重发；已生效效果按原期限收尾。
