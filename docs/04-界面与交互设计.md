## 方案 A 实施约定

用户已选择青瓦城关风格。共用暖白背景、轻页头、青玉铜框图标和朱红主动作，首页／战场／内页使用同一套建筑与插画。军功保留真实值与晋升进度；升级使用建筑檐角箭头，门槛与消耗放在玩法介绍中；策略详情默认只呈现效果／目标／数量，其余说明通过浮层内“详细规则”展开；结算默认强调名次、实际增减和真实奖励资格，完整四方战绩通过“查看战报”展开。展开不写存档、不自动执行战斗操作，旧隐藏回调失效。各页返回来源、固定继续、改策取消、存储失败保护等现行合同保留。

A01 样板将队旗纹样和准确整队兵数合并为跟队旗牌，优先队首侧上方，附近稳定避让营地和其他标签，拥挤时沿用军情逐队查询。旗牌按出发人数预留固定宽度，真实剩余人数采用等宽数字右对齐；例如 10→9 时不缩框，真实受击仍显示减员提示。行走帧不改变数字、命中或时钟。暂停保留原尺寸冻结战场，前景使用紧凑操作弹层。四类军士以六帧表现脚步，不改变真实行军方向、人数和距离。

## 手机操作流程（本轮实施规范）

保留方案 A 美术，首页用单一出征和小图标入口，成熟玩家无待处理事项时直接开局；首次玩家／未确认结果／待领卡／恢复优先级保留。战前信息仍可查，但不强制每局经过准备页。点城仅查当前产兵速度与容量，点檐角箭头升级；策略点选后点目标，兼行点选后随下一次拖兵生效。卡册和准备里的策略说明在原页面浮层内展开，关闭不改变浏览位置。结算以真实收益、短动效和领奖／再来一局为主，战绩／首页作为次要入口。默认不保留长说明，首次操作短指引与完整规则入口并存。交易完成后才能反馈成功；取消、无效目标和旧回调不消费。具体边界与验收见[手机流程施工清单](../goals/20260912-2309-mobile-game-flow.md)。

玩法与关于默认显示“操作图解”，用派兵、升级、锦囊三图解释手势；顶部可切换“详细规则”，保留九节完整说明。两类内容分别滚动，切换回到顶部并清除旧展开；演示不操作实际战场、不开局、不消费。减少动态为静态手势。返回仍回设置及原来源。

练兵选关以三处沿山径排列的建筑作为入口，按 L01／L02／L03 从上到下阅读；题签保留实际关名、一键进入和已通关／可练习／未解锁状态，不增加星级、奖励或强制全通。装饰山径不代表对局道路。顶部返回固定，内容小屏可滚动；奖励边界与已有记录下的临时练兵提示保留。

## B1. 全部页面与回路

全局：同一时刻一个主页面＋至多一个模态；错误/平台必须事项优先。返回关闭当前浮层回来源页，不串跳首页。战斗中打开设置先进入暂停；用户必须明确继续才推进游戏。

S06 设置采用居中紧凑浮层：首页来源保留青瓦城关，暂停来源保留冻结战场，背景不接受点击。关闭与“完成”固定，中间三项开关、试听及次入口小屏可滚动。回到来源页不自动继续对战；进入玩法／关于再返回时保留来源。清除记录仍由独立确认层承载，不在设置页直接执行。

浏览器 Escape 与当前返回层级一致：先取消确认浮层或未提交的派兵／用策／营地查询，再在无上述操作时暂停战斗；其他页面执行已显示的返回动作，首页不触发主动作。忽略按住按键产生的重复事件。确认浮层关闭或替换后，其旧确认回调失效；恢复页没有可读资料时不提供通向首页的返回入口，保留重读与临时练兵。

浏览器键盘操作区更新库存等文字时保留当前操作焦点。焦点已在操作区时，打开或替换确认浮层默认聚焦“取消”，同一浮层刷新不覆盖用户已选择的按钮，关闭后回到原入口；入口已不存在则落到当前首个可用操作。焦点在操作区外时不因绘制刷新强制移入。

已从键盘操作区移除的旧按钮不再执行动作，即使后续页面复用了同一动作 ID，也不能将旧点击转交给新按钮。临时无奖励练兵的暂停页显示“退出临时练兵”；退出后释放临时会话，有资料时返回首页并可继续原已保存对局，无可读资料时回记录处理页。无资料的临时战报返回同样进入记录处理页，不进入空首页。

首页在可用高度不足时滚动标题下方内容，标题与设置固定在安全区内；关闭周摘要或扩大窗口后收回多余滚动距离。裁切后不足 44 px 高的首页按钮暂不接受点击，滚动至完整显示后可用，避免只露出窄条的触控目标。

所有入口必须有真实目标和禁用/失败说明。未实现的解锁或发布功能不能先显示成功态。无商城、皮肤、红包、VIP、匹配房间、复活/继续广告或广告伪入口。

## B2. 首页和首次/回流流程

### B2.1 首页层级

首页使用已选出征前庭插画、薄铜控件和朱漆军令牌。顶部为“谋定山河”、可点击军衔徽及设置；底部练兵、策略、周榜横排为器物图标及短标签。城门仅作背景，不设假城池操作或常驻玩法段落。主动作旁的小地图可主动查看战前情报。默认不显示本周进度长栏，周胜在周榜、兵法和库存从策略入口查看。

领取被动或周更时，在军衔下方、主动作上方的可滚动区域显示真实变化，不能覆盖底栏或主按钮。永久未解锁卡说明对应练兵关，不能写成缺胜场；无待领不挂常亮红点，无卡不显示缺资源警告。

### B2.2 主动作优先级

1. 存档/事务不确定：先 S07，“恢复存档”，不能开始正式局覆盖。
2. 已保存未确认结果：S04，“查看上局结果”；确认过结果但尚有选择时主按钮“领取策略”，到 S09。
3. 有可恢复战斗：“继续对战”，到 S03；不进新准备页。
4. L01 未首胜：“开始练兵”，到 L01。
5. 其余：“出征”，直接开始正式局；S08 通过次入口按需查看。

上述是首屏/主按钮规则，不禁止用户查看设置/规则/榜单；待处理结果或续战期间进入无奖励练兵前提示其不覆盖正式存档，使用独立临时练习会话。平台必须同意项按平台实际要求处理；不假定无需任何合规提示。

### B2.3 三条闭环

- 新用户：资源可用 → 首页 → L01 首次引导 → 首胜结果／解锁正式、L02 及首批卡池资格（军功不变、不赠卡） → 建议下一课，次动作“开始征战” → S08 → 正式局。
- L03 胜利后已无下一课：主动作“开始征战”，次动作“返回首页”。两个入口分别直接开始正式局和返回首页，均先确认已有结算，不重复解锁或发奖。
- 老用户：读档/切周 → 首页 → 直接对战（S08 只通过“战前情报”按需查看） → 结果 → 有奖从主动／被动混合候选只选一张 → 保存反馈 → 直接再来一局。
- 中断用户：后台停战/存检查点 → 回前台 S03 → 明确继续原局；冷启动有效快照同样恢复，结果已保存则去结果而非重算。过期/不兼容快照进入 S07：兼容过期正式局确认弃战按新局 0／旧局扣 10 结算，取消不能另开正式；技术故障按 E 恢复或技术作废，不静默认输。恢复副本的确认绑定所展示的代次、版本、时间和校验标识；重读后副本变化则取消旧确认，重新展示该副本的时间与回退风险。

### B2.4 原创卡册与选策表现

策略库使用两列竖幅卡册，单卡详情为原页面的小浮层，展示插画、解锁条件、精确库存或层数与核心效果，完整规则及到期按需展开；关闭恢复卡册或战前原位置及展开状态。冠军选策将实际的一至三张候选并排呈现，选中后在下方显示完整名称与领取前后效果；被动百分比直接标明“产兵”“移速”或“容量”，不以泛称“增益”代替。小屏说明可滚动，确认和放弃固定在底部。战前清单与战场四短标引用同一幅策略插画，战场仍保持至少 44 px 点击区域。

图片加载／重试改变布局时，取消尚未松开的手势，旧布局回调失效；已经明确选中的策略保持不变。改选后旧确认回调也失效，不得领取新选择。图片加载失败不阻塞读取或保存，设置页保留失败和重试；成功载入数量收进关于，不占常态设置页。

## B3. 小屏战场布局

暂停页“继续对战”固定在底部安全区，无需滚动查找；地图、兵法、军情和退出等其余内容可滚动，不侵入固定按钮。

战场不常驻“查看行军”按钮。军情入口置于暂停页，打开和查询期间保持战斗冻结；按到达时间逐队列出阵营旗形、当前兵种／精确人数、源营与目的地方位、剩余到达时间和弓兵齐射状态，分页覆盖全部队伍，不合并兵数。点击一队查看其目标营地详情仍保持暂停；返回或 Escape 回到来源层，只有明确“继续”才推进战斗。已消失队伍的旧操作不可定位其他队伍，查询层不能穿透派兵。

基准 375×812，必须另验 320×568 与 430×932。全部使用屏幕逻辑尺寸；微信安全区/胶囊按实际测量，不画假胶囊。

微信胶囊底边有效时，内容从其下方 6 px 与设备安全区较大值开始；接口缺失、异常或返回无效坐标时，在设备顶部安全区之后预留 44 px 菜单行，窗口变化和回前台重新计算。该留白是本项目回退策略，不是某个机型的固定坐标；完整触区须避开系统菜单。接口坐标原点依据 [微信官方 API 类型说明](https://github.com/wechat-miniprogram/minigame-api-typings/blob/master/types/wx/lib.wx.api.d.ts)。

浏览器使用 CSS `env(safe-area-inset-top)`／`env(safe-area-inset-bottom)` 获取实际留白，按 Canvas 相对窗口的位置计算重叠部分，不乘设备像素比、不对已内缩的画布重复留白；至少保留顶部 16、底部 12 的常规间距，键盘操作区顶部与画布内容一致。无法取得环境值时沿用常规间距。`viewport-fit=cover` 与安全区的配合依据见 [WebKit 官方说明](https://webkit.org/blog/7929/designing-websites-for-iphone-x/)。

上区：安全区后约 52 高内放小暂停入口、我的城数／存活方数和倒计时；余量不足时阵营小旗与计时拆成两行，不能重叠系统控件。四方显示“03:12”“我方 2 城 · 剩 3 方”，不常驻总战力／军衔／金币或机制说明。

下区：安全区前约 72 高，常态只有四张主动插画小卡，名称短词和库存清晰，命中区域各至少 44×44。被动层数／百分比移入暂停查询，不常驻第二行说明。轻点城池显示就近两行短签：当前产兵速度、容量；不包含升级说明或详情入口。点城、拖动和选策均不改变地图坐标或缩放，教学只保留当前一步提示。

战场占剩余区域，比例 360:540，缩放 k=min(可用宽/360,可用高/540)，居中不裁城。触控目标独立扩为 44×44，兵数 16、辅助 13、正文 15 至 16 不随 k 无限缩小。小屏先省小景/装饰/长说明，再缩战场；关键触控不重叠才通过。

例：320×568，按常规顶部留白 16 加顶栏 52、底部留白 12 加底栏 72，余高 416，k≈0.7704；最小城距 105 映射约 80.9，大于 44。仅说明布局可行，不替代不同实际胶囊／安全区检验。若实际可用区无法满足触控，显示“请竖屏使用／调整窗口”，暂停，不裁掉功能。

空间不足的提示覆盖所有页面，不能下一帧变为被裁切的暂停菜单。缩窗立即取消未提交输入并暂停已接受的开局／当前对局；帧循环在推进模拟前检查可用空间，不反复排队暂停保存。尺寸恢复后仍须明确继续，不补算等待时间；尺寸变化前绘制的旧操作不得继续执行。

## B4. 原创视觉规范

成品美术以 G2.1.3 覆盖本节旧的纯几何沙盘表现。保留本节尺寸、旗形、归属色与信息约束，采用真实插画素材、轻量标题与干净正文。策略库和选策显示独立主题插画＋实时文字，战场四主动使用同源主体缩略图；素材内不印制数值。所有加载失败、存档异常、暂停与确认仍可清楚操作，不能只完成正常页面。

时代：汉末三国·群雄军阵。方向：轻国风彩绘军棋沙盘。2D 正视可读城池＋少量斜面，简洁木质边缘与布旗；不使用写实战争血腥或复杂武将立绘。三个地图共用基础美术，只用小标题/局部低对比点缀区分资源布局，不加装饰碰撞。

## B5. 城池、军士与战斗状态

触摸范围应覆盖各级建筑的可见主体，尤其是高塔与三级城堡上半部，不能只覆盖基座和数字牌；相邻营地重叠时按距离稳定选择，页面控件与弹层仍优先。没有从己方营地开始的拖动，松手时不得变成对目标城的点击查询或施策；轻点查询与合法源点派兵保持原有行为。

松手时使用末次坐标补齐拖动判定和未处理的滚动距离，即使平台没有发送中间移动事件也不能误触按钮；页面、布局或输入上下文失效的旧手势仍取消。玩法说明展开、收起及画幅变化时，滚动位置立即收回到实际折行内容边界，首次上滑不得反向回弹。

第二课在己方一级营地达到升级门槛时，于既有底栏显示一句“轻点升级”的操作提示，并写明营地类型；选中营地、拖兵或选策时让位给当前操作，升级完成或条件不再满足即收起。提示不新增按钮、遮罩或暂停，不代替真实升级条件，也不改变教学数值。

城池四信息层：类型剪影 → 阵营旗 → 实际驻军数 → I／II／III 小标。驻军使用贴近城门的低矮军旗标牌，固定中心，等宽数字至少 16 px，按整数位数扩宽，不缩写成约数或白色表单块。容量只在查询／满仓时提示，不把每城都画成血条 HUD。不常驻“末城”文字；真实己方最后一城收到已出发来袭后才局部提示。点选塔营显示真实射程，取消查询后收起范围。

瞬态浮字与行军数量标签同时避让营地及其危险／持续状态。行军标签按队伍 ID 保留相对偏移，优先固定跟队，仅遮挡时在队伍附近约 40 px 内局部避让，不跨地图寻找空位。小屏无空位时优先保留归属、驻军、危险状态与队首，省略冗余装饰浮字；未显示的队伍人数可在暂停军情逐队查询，具体层级见 05 G6.1。

行军标签仅保留小旗与当前精确兵数，不常驻兵种或“待／射／跳”文字；兵种靠原创小兵轮廓，齐射完整状态在军情与营地详情查询。普通说明文字以 [W3C 文字对比度要求](https://www.w3.org/TR/WCAG22/#contrast-minimum) 的 4.5∶1 为最低参考，色值算术检查不代替实际画面检查。

普通营地不因敌军进入装饰圈而伤害；塔营按真实射程与射击事件攻击路过敌队和范围内敌营驻军。装饰小兵数量不等于兵团实际数量，标签一直可查。拥挤时合并视觉尾迹但不能合并不同规则到达事件。

### B5.1 转换、塔射、齐射与升级的输入状态

- 到达转换：完整详情明确“骑兵 → 弓兵（到达后）”；敌营写“占领成功后转换”，不承诺必胜。拖拽只突出派／留、真实旅时与塔射危险，归队后只保留本营一种驻军数字，不显示混编三排库存。
- 暂停军情中四类营地的完整详情均写明友援／占领后转换为本营兵种、存活兵力 1∶1 转换及途中不换兵；弓营齐射与塔营射击说明不能代替转换说明。
- 箭塔：选中显示实际 120 范围，射频在暂停军情详情中查询；拖动经过范围提示“可能遭塔射”，不是必受固定伤亡承诺。范围内的敌营受射可见箭迹／实际扣数，清零仍显示原旗，不播占领动画。
- 升级：己方非满级城达到门槛后，建筑檐角显示约 10px 向上箭头，44px 触区保持。点箭头直接升级，从箭头拖动则派兵。点城短签只查产速与容量，并避让该城升级触区；门槛与消耗在玩法图解及详细规则中说明：30 兵耗 10 升二级，70 兵耗 25 升三级。敌方、中立、满级和未达门槛城不显示箭头。
- 点击升级按玩法介绍中的固定门槛与消耗提交，不再弹全屏模态；提交时重验人数／归属／终局。失败不扣兵，未知写入保护暂停；同一提交未结束时不重复接受升级，旧等级按钮不能按新等级成本执行。成功后更新等级与留守，收起查询短签恢复策略栏，短提示“已升至二级／三级”，不要求额外关闭；失败不播放成功反馈。动画不锁下一操作。
- 选卡／派兵时收起查询短签；查询短签可与所选己城的檐角升级箭头共存，整张短签（含文字空白区）起手不穿透地图。成功出兵恢复常态策略栏。升级不改变旧在途队兵种、速度或塔射既定下一发。
- 暂停军情的弓营详情写“出征齐射一次，驻营不自动射击”，说明 70 范围、出发至少 0.5 秒及当前人数 30%向下取整；不在弓营建筑周围画自动防御圈。
- 弓兵详情说明“先齐射，再到达”，理论伤害注明途中损失和目标变化会影响结果，不是预扣或保证夺城；常态拖拽不展开齐射机制长文。齐射没有独立按钮，不需玩家再次点射。
- 查询目标营地的在途列表时显示各弓兵队的待齐射／已齐射／已跳过、剩余人数、预计检查时间和 ETA。准备阶段可写“准备齐射”，射击后不显示会循环恢复的冷却条；跳过说明友方／空营／人数不足取整，不误报命中。
- 战场缩放低于 0.8 时，持续状态使用短标“鼓令”“停产/射”“耗尽”，分别表示仍在计时的鼓令、塔营停产兼停射、增募额度用尽；剩余秒向上取整，避免有效期间显示 0 秒。普通画幅与查询保留小数期限；短标和完整文字采用同一避让占位，不能与相邻城状态重叠。
- 查询的“产速：基础 → 当前”按此刻有效生产速率显示：计入本营等级、所属方被动和仍有额度的征兵加速；火袭停产、满仓或无有效所属方时为 0。征兵额度用尽即恢复自然产速，到期不继续加速；这是当前速率，不承诺下一整秒产量。升级页的“自然产速”仍单独比较升级前后的自然速率。
- 行军标签只在队伍附近有界避让，数字位数变化不触发无故换侧；无空位保留实际队首与暂停军情查询，不用长引线把兵数放到远处，不合并不同队伍兵数。营地数字、旗标和持续状态优先，装饰反馈后放置。
- 齐射命中仅在目的营地标实际损失，空营仍保留原旗；同刻合计只显示一次总损失，不按各队理论值虚报溢出伤害。已跳过不播命中箭束，减少动态仍保留静态状态与扣数。
- 仅实现基础整编而未实现齐射的原型仍须标明范围；文字规格和动画本身不算弓兵战斗实现完成。

## B6. 主动、被动与选择的具体手势

战前默认显示地图、四张主动小卡及库存、本周被动兵法摘要，不常驻七策长表。通过“查看策略详情”进入完整七策，查看统一图标、完整名称、主动库存／被动层数、实际效果或未解锁状态；返回原战前页，不消费或自动开局。军功规则默认折叠，底部“开始对战”固定可用。

底部保持四个固定位置，依次用 G2 两字短标“征兵/兼行/乡勇/火袭”；详情、选策和策略库用四字全名，避免小屏挤四个长名称。未解锁位置为低强调锁定说明，不可施放；只有七张首发卡出现在图鉴，H 储备不展示。主动卡不接受拖动施放；点已解锁且有库存的卡进入待施放，不扣张；点有效城确认鸣鼓征兵/征召乡勇/火袭粮营，倍道兼行要求接着完成一次有实际 ETA 收益的合法拖拽派兵。点空白、再点已选卡、返回/暂停/后台取消；切换另一张卡取消旧准备。源易主或到期不“自动帮玩家换目标”。

待施放时底部显示成本/实际作用，“征召乡勇+2（容量限制）”“鸣鼓征兵 5 秒→11 秒，增募额度 +8，消耗 1”；同名续时不是×4。短按确认后不再叠加第三次确认；用户已从预览知晓成本。保存成功即更新库存、效果与战场；动画不锁下一次合法用策。同手势不重复消费，不同手势可以连续用完库存。合法路长 200 的无被动步兵兼行预览“普通 8.33 秒 → 加急 5.95 秒”；若两者整数毫秒相同则显示“此路线无需加急”，松手整次取消，不扣卡/兵、不建队，仍可另选路线或显式取消兼行后普通派兵。精确校验用整数毫秒，不用两位小数显示值；整数不同但两位小数相同时，预览增加到三位小数，例如“普通 1.001 → 加急 1.000 秒”，让实际收益可见。

耗尽态仍可点看说明“获胜可选择”，不可弹商店。满仓等无效目标有原因且不扣；所有城均无效时提示“当前没有有效目标”，可取消。周到期即时更新灰态，不能播放技能但不生效。

被动为状态不是释放按钮：在暂停展开军情或策略详情显示如“屯田 · 3 层 · 产兵 +8.57%”，说明“本周每局自动，不消耗”；战场不占用常驻被动条。跨周旧局在查询中注明“仅本局继续生效”。策略库用插画卡册呈现七策，格内数量可简写为 999+，详情必须显示精确可增长整数层数，不写成“剩余 2 张”或只做三级填充；永久资格和当周拥有分开展示。

S09 采用最多三张并排竖幅候选卡，页首写“只选一张”；每卡独立标主动／被动和名称，选中后在下方显示实际作用、当前→领取后及到期。主动写“库存 2→3，每用扣 1”，被动写“层数 3→4，本周每局自动”，并展示递减后的实际属性。候选通常为 2 主动＋1 被动，按 D2.3 从已解锁白名单抽取；不足按实际展示，不凑重复卡。确认成功回结果摘要，没有第二份奖励，不展示名次抢选倒计时。

## B7. 结果、周榜和异常文案

结算摘要保留真实军功增减与当前军功；“军功最低为 0，本次实际扣除…”的下限说明收进展开战报，避免在小屏重复说明挤掉入口。320×568 的微信安全区内，普通零军功败局初始即可点“查看战报”，触控高度至少 44；底部主动作固定，展开／收起只改变阅读状态，收起时回到摘要顶部，不保留长内容的滚动空白。

## B8. 动效、声音与减少动态

下表约束通用时长；逐卡视觉符号/分镜、出兵全过程和并发优先级以 G4 至 G6 为专项补充，不能用同一个光圈替代全部效果。逻辑数值与有效归属始终立即正确，保存未明确成功时不播成功施策。

| 事件 | 时长基线 | 表现与约束 |
| --- | --- | --- |
| 按下/选中 | 60 至 100ms | 描边或≤3%缩放，不移动触控区 |
| 路线变化 | ≤80ms | 跟手单线，禁止惯性追赶 |
| 派兵 | 450 游戏 ms | 源点轻反馈，队伍立刻出现；不延迟扣兵 |
| 到达/兵数变化 | 接战／归队 550 游戏 ms，数字即时 | 数字立即更新，短小增减；不慢慢滚真实兵数 |
| 夺城 | 800 游戏 ms | 旗切换与短色彩过渡，不全屏文字 |
| 最后城受袭 | 200 至 350ms | 局部提示；同城 3 秒内不重复强提醒 |
| 主动施放/续时 | 150 至 250/100 至 180ms | 作用目标小图标；续时标 +6 秒／+4 秒；鼓令另显示新增预算 |
| 营地升级／兵种转换 | 升级 220 游戏 ms；转换随归队 550／夺城 800 游戏 ms | 权威状态先更新；保留实际扣兵、等级与新兵种，不播放免费增兵或混编 |
| 塔射命中 | 300 游戏 ms | 短箭迹与真实扣数；不依赖视觉飞行再算第二次伤害 |
| 弓兵齐射 | 300 游戏 ms | 队首一次短箭束，队伍不停步；状态与实际损失即时更新，不额外延长准备或旅时 |
| 被动开局生效 | 即时 | 规则快照立即正确，暂停／详情可查最多 3 种被动及任意合法层数，战场不另占条或逐张演出 |
| 选策入库/强化 | 180 至 300ms | 保存后变化，数量/层数分别表示 |
| 军功/军衔变化 | 升级 200 至 350ms；扣分/降级 100 至 160ms | 数值一次即时更新；跨衔上升短换旗，下降克制说明，历史最高可查；不挡再战 |
| 页面/暂停弹层 | 150 至 220ms | 简单淡入，战斗先暂停 |
| 正常终局到可操作 | ≤600ms | 以结算已一致提交为前提；保存异常显示恢复状态，不放行不确定奖励 |

声音 7 类：点击/出兵/到达/夺城/胜/负/军令；新增军令含征兵短鼓、乡勇集合木签、火袭短火星 3 个短变体，兼行复用出兵加急变体；同类 100ms 内合并，最多 4 声音并发；背景音乐首版不必制作，不用静音时仍循环的资源。震动只用于夺城或最后城首次受袭，至少 500ms 间隔，默认关闭，可设置开启；声音默认开启但尊重设备/平台静音能力，切后台立即停。

暂停保留原尺寸冻结战场，以深色遮罩和居中暖白弹层承载操作；不再跳到整页战场缩略图。弹层突出“继续对战”，回首页／设置为次操作，放弃必须进入确认层；军情按需展开。背景不注册派兵／施策区域，不推进战斗，读档后仍明确继续才恢复。过期与临时练兵保留各自真实提示，小屏必要时仅弹层内容滚动，主按钮固定。

本地页面与确认层采用 180 ms 低对比淡入，以独立 UI 时间推进，不移动布局；文字与按钮第一帧即显示并可操作，战斗先暂停。普通页面重绘不反复播放，不等待动画才放行已提交的结果。

减少动态取消缩放弹跳、位移尾迹、循环强调及镜头震动；保留即时数字、静态阵营/受袭图标和必要轻淡入。全局不使用闪屏、相机震屏或长强制庆祝。关闭音/震也能完整理解战况。

## B9. 素材清单与未来设计验收

首批设计资产：12 个营地轮廓（4 类×3 级）、4 种对应兵种基础形、5 阵营旗形、7 策略图标、8 军衔旗饰、1 共用背景、1 工作字标、约 12 功能图标、7 类短音效（军令 3 个短变体）；G7 列出复用的轻量特效素材，弓兵齐射复用短箭贴片与短弦音变体。阵营颜色可程序换色，不制作 12×5 全套重复建筑；尺寸不同复用同源资产，避免下载整套中文字体。

结果优先显示本局实际“军功 +N／−N”、当前军衔和简短原因，前后精确值可作次级信息，不展开整套晋升表；历史最高只在详情或跨衔摘要记“曾达”。旧局例如 3→0 写“实扣 3（0 分下限）”，不能显示 −10 再让数值只减 3。放弃确认按新旧约定列不扣分或实际扣分及前后值，已用锦囊不返还，不因精简隐藏后果；负分不碎旗、不播嘲讽音。

后续 Figma 仅在用户另行授权后制作，至少覆盖：S01 五种主状态；S02 教学／拖拽／末城／倒计时／塔射范围／到达转换／升级有效无效；四主动有效无效续时；被动自动/强化/跨周；S04 胜负/并列/挂机/弃战与实计军功、降级/历史最高、首胜唯一混合奖励；S09 待领失败；S13 加载授权空榜离线；S07 恢复与两种重置。所有关键页面另验 320×568，不以画稿数量代替观感与操作验收。

本次未制作任何资产、屏幕原型或动效文件；表中时长、颜色和清单是可交接设计规格。

## 本轮战场体验细化

城池短签只显示当前产兵速度和容量，关闭为轻量叉形；升级由檐角箭头一步提交，说明移到玩法介绍。战场策略小卡使用同源军士与营地造型、两字名称和精确库存；可用目标采用贴地椭圆轮廓。

手机窄屏无法同时避开所有营地时，城池短签先保证选中营地的触摸区、檐角升级触区和 8 px 间隔，再保证卡片就近（卡边距离不超过 52 px），最后最小化其他营地遮挡。允许临时覆盖少量未选营地，不能为避让把卡片放到战场另一端；关闭后恢复完整战场。
