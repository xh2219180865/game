# 界面与交互设计

更新：2026-09-10。v1.4 本文是文字制作规格，不是已完成的原型/Figma/美术验收。规则源为[主文档](01-产品与玩法设计.md)、[D](03-策略与军衔设计.md)和[E](06-技术与存储设计.md)。时代、逐策动效/出兵分镜和军衔旗饰的专项制作规格见[G](05-美术与动效设计.md)。

## B1. 全部页面与回路

全局：同一时刻一个主页面＋至多一个模态；错误/平台必须事项优先。返回关闭当前浮层回来源页，不串跳首页。战斗中打开设置先进入暂停；用户必须明确继续才推进游戏。

| ID | 页面/载体 | 必须内容与状态 | 主动作 | 返回/次动作 |
| --- | --- | --- | --- | --- |
| S00 | 启动/资源页 | 真实加载、读档检查、可重试错误，无假百分比 | 完成后自动按 B2 路由 | 失败重试；可用时无奖励练兵 |
| S01 | 首页 | 当前军衔、一个主动作、本周进度、次入口 | 按 B2 优先级显示 | 策略库、练兵、军衔、好友周榜、设置 |

| S03 | 暂停/续战浮层 | 地图、已用时、被动快照、保存状态 | 继续 | 保存回首页；放弃并重开需确认 |

| S11 | 军衔页 | 当前军职/军功/级内进度、八衔路线、历史最高、无战斗属性、加扣规则 | 返回 | 不显示金币/职位/付费升级 |

| S13 | 好友周榜 | 本周冠军数、同分并列、我的条目、更新时间、非实时对战说明 | 刷新/按需授权 | 首页；关闭展示与上传见 E |

| S15 | 破坏性确认浮层 | 放弃战斗/放弃机会/清本地/删本人托管分四种明确对象 | 明确动词确认 | 默认焦点为取消；不预勾“同时删全部” |

所有入口必须有真实目标和禁用/失败说明。未实现的解锁或发布功能不能先显示成功态。无商城、皮肤、红包、VIP、匹配房间、复活/继续广告或广告伪入口。

## B2. 首页和首次/回流流程

### B2.1 首页层级

顶部：工作名“四方夺城”、小军旗名片“军司马 · 二级”、设置入口，避开微信胶囊。中部：一幅低对比军棋沙盘小景，不放可以误触的假城池；一句“拖出一半兵，四方争一胜”。主按钮一枚，次入口分为“练兵”“本周策略”“好友周榜”，军衔名片本身可点。

周进度只显示“本周 3 胜 · 已拥有 2 种兵法”等真实摘要，详情区分冠军次数、主动库存和被动层数；不画被动里程碑／满层进度条。永久未解锁卡说明对应练兵关，不能写成缺胜场。无待领不挂常亮红点，无卡也不显示缺资源警告。

### B2.2 主动作优先级

1. 存档/事务不确定：先 S07，“恢复存档”，不能开始正式局覆盖。
2. 已保存未确认结果：S04，“查看上局结果”；确认过结果但尚有选择时主按钮“领取策略”，到 S09。
3. 有可恢复战斗：“继续对战”，到 S03；不进新准备页。
4. L01 未首胜：“开始练兵”，到 L01。
5. 其余：“四方夺城”，到 S08。

上述是首屏/主按钮规则，不禁止用户查看设置/规则/榜单；待处理结果或续战期间进入无奖励练兵前提示其不覆盖正式存档，使用独立临时练习会话。平台必须同意项按平台实际要求处理；不假定无需任何合规提示。

### B2.3 三条闭环

- 新用户：资源可用 → 首页 → L01 首次引导 → 首胜结果／解锁正式、L02 及首批卡池资格（军功不变、不赠卡） → 建议下一课，次动作“进入四方” → S08 → 正式局。
- 老用户：读档/切周 → 首页 → S08（默认总是展示，可快速确认，不做再增加一层确认）→ 对战 → 结果 → 有奖从主动／被动混合候选只选一张 → 保存反馈 → 再战准备。
- 中断用户：后台停战/存检查点 → 回前台 S03 → 明确继续原局；冷启动有效快照同样恢复，结果已保存则去结果而非重算。过期/不兼容快照进入 S07：兼容过期正式局确认弃战才扣 10，取消不能另开正式；技术故障按 E 恢复或技术作废，不静默认输。

## B3. 小屏战场布局

基准 375×812，必须另验 320×568 与 430×932。全部使用屏幕逻辑尺寸；微信安全区/胶囊按实际测量，不画假胶囊。

上区：安全区后 48 高内放暂停、我的城数/存活方数和倒计时；余量不足时阵营小旗与计时拆成两行，不能重叠系统控件。四方显示“03:12”“我方 2 城 · 剩 3 方”，不常驻总战力/军衔/金币。

下区：安全区前至少 112 高，第一行 4 个主动按钮各至少 44×44，有名称短词和库存；第二行提示/可折叠被动状态。详情展开占用该提示区，长说明进入暂停后的规则页，不盖地图。教学下区只用提示，不显示七张陌生卡。

战场占剩余区域，比例 360:540，缩放 k=min(可用宽/360,可用高/540)，居中不裁城。触控目标独立扩为 44×44，兵数 16、辅助 13、正文 15 至 16 不随 k 无限缩小。小屏先省小景/装饰/长说明，再缩战场；关键触控不重叠才通过。

例：320×568，预留顶部 72、下部 128（包含本例安全留白），余高 368，k≈0.6815；最小城距 105 映射约 71.6，大于 44。仅说明布局可行，不替代不同实际胶囊/安全区检验。若实际可用区无法满足触控，显示“请竖屏使用/调整窗口”，暂停，不裁掉功能。

## B4. 原创视觉规范

时代：汉末三国·群雄军阵。方向：轻国风彩绘军棋沙盘。2D 正视可读城池＋少量斜面，简洁木质边缘与布旗；不使用写实战争血腥或复杂武将立绘。三个地图共用基础美术，只用小标题/局部低对比点缀区分资源布局，不加装饰碰撞。

| Token | 颜色 | 使用与前景 |
| --- | --- | --- |
| paper | #F3E8D4 | 暖浅底；正文用 ink |
| ink | #253B45 | 正文/数字/轮廓 |
| player | #176D70 | 玩家青色，白字，菱形旗 |
| enemy1 | #B13D36 | 电脑甲朱色，白字，三角旗 |
| enemy2 | #C99A32 | 电脑乙金色，ink 字，圆旗；禁止白字 |
| enemy3 | #5F579C | 电脑丙紫色，白字，方旗 |
| neutral | #D8D0C2 | 中立，ink 字，空心旗 |
| surface | #FFFDF7 | 面板，ink 字；不使用半透明纹理压正文 |

阵营名：你＝青旗军；电脑甲＝赤旗军、电脑乙＝金旗军、电脑丙＝紫旗军，标签保留“电脑”。它们是架空演练军阵，不声称史实国号、旗色或真实玩家。军帐、弓架、马栏、固定塔楼分别服务步兵营、弓营、骑营、塔营，装饰不能暗示未定义技能。

颜色仅区分归属，类型靠轮廓（步兵营军帐／弓营弓架／骑营马栏／塔营塔楼），等级 I／II／III 固定小标。敌人也带“电脑甲/乙/丙”说明，不伪造真人头像。玩家旗始终菱形，色觉差异下仍能认。

普通中文用平台可用清晰无衬线字体，标题用同族较粗字重；不依赖大体积自定义书法字库。若定制 logo 仅独立字标，不替换游戏数字字体；素材授权记录见 F。数字等宽，不能让 999→1000 横向跳动影响按钮。

间距基于 4/8/12/16/24，页面左右 16（小屏 12）；控件圆角 12、面板 16。阴影至多一层弱接触影，无玻璃霓虹/连续流光。对比计算基线：paper/ink 约 9.67:1；青/朱/紫白字均大于 5.8:1；金底 ink 约 4.55:1，中立 ink 约 7.66:1。不可把这些色值随意加透明度后沿用对比结论，真图需重测。

## B5. 城池、军士与战斗状态

城池四信息层：类型剪影 → 阵营旗 → 实际驻军数（城内字号最大） → I／II／III。容量只在查询/满仓时提示，不把每城都画成血条 HUD。最后城显示一个稳定标记，收到已出发来袭后局部强调；点选塔营显示真实射程；普通营地不画假的防御圈，取消查询后收起范围避免全图叠圈。

| 状态 | 呈现 | 输入/退出 |
| --- | --- | --- |
| 首次教学 | 单条手势与“拖到这里，派出一半兵力” | 整个模拟冻结，只接指定第一次派兵 |
| 按住源点 | 选中描边、派出 X/留守 Y | 兵数随状态更新；轻点转查询 |
| 有效拖拽 | 单条路线、预计 ETA、目的旗 | 松手成功；非保证攻占 |
| 无效拖拽 | 撤掉目标高亮、必要短原因 | 取消不扣；源易主立即清预览 |
| 行军 | 少量军士、阵营旗、实际数量 | 不等动画结束可继续派兵 |
| 到达 | 数字立即更新，短增减反馈 | 逻辑先结算，不串行等待多个特效 |
| 夺城 | 旗帜切换与轮廓换色 | 城已归新主即可操作，不被占领动画锁住 |
| 最后一城 | 稳定标记；受袭再局部强调 | 仍可调兵/征召乡勇，不提供临时免死 |
| 最后 30 秒 | 一次“到时城多者胜；同城数比兵力” | 不改变规则、不加速模拟 |
| 终局 | 冻结，取消未提交动作 | 正常保存完成后 600ms 内结果主动作可用；保存异常转恢复，不伪造可领取 |

普通营地不因敌军进入装饰圈而伤害；塔营按真实射程与射击事件攻击路过敌队和范围内敌营驻军。装饰小兵数量不等于兵团实际数量，标签一直可查。拥挤时合并视觉尾迹但不能合并不同规则到达事件。

### B5.1 转换、塔射与升级的输入状态

- 到达转换：预览明确“骑兵 → 弓兵（到达后）”；敌营写“占领成功后转换”，不承诺必胜。归队后只保留本营一种驻军数字，不显示混编三排库存。
- 箭塔：选中显示实际 120 范围和射频；拖动经过范围提示“可能遭塔射”，不是必受固定伤亡承诺。范围内的敌营受射可见箭迹／实际扣数，清零仍显示原旗，不播占领动画。
- 升级：点己营进入底部查询面板，面板暂替换策略栏，不叠出第二排遮地图。显示门槛、消耗、升级后留守／容量／产速，升级按钮至少 44×44；不足、三级、非己方有具体原因。
- 点击升级以已展示成本作为确认，不再弹全屏模态；提交时重验人数／归属／终局。失败不扣兵，未知写入保护暂停；成功后立即更新等级与留守，动画不锁下一操作。
- 选卡／派兵／升级面板互斥，UI 起手不穿透地图。升级不改变旧在途队兵种、速度或塔射既定下一发，查询显示真实新属性。
- 弓兵移动远程规则未定前，Figma／原型须标“基础整编示例”，不制作假伤害来冒充已完成特色战斗。

## B6. 主动、被动与选择的具体手势

底部保持四个固定位置，依次用 G2 两字短标“征兵/兼行/乡勇/火袭”；详情、选策和策略库用四字全名，避免小屏挤四个长名称。未解锁位置为低强调锁定说明，不可施放；只有七张首发卡出现在图鉴，H 储备不展示。点已解锁卡只进入待施放，不扣张；点有效城确认鸣鼓征兵/征召乡勇/火袭粮营，倍道兼行要求接着完成一次有实际 ETA 收益的合法拖拽派兵。点空白、再点已选卡、返回/暂停/后台取消；切换另一张卡取消旧准备。源易主或到期不“自动帮玩家换目标”。

待施放时底部显示成本/实际作用，“征召乡勇+2（容量限制）”“鸣鼓征兵 5 秒→11 秒，增募额度 +8，消耗 1”；同名续时不是×4。短按确认后不再叠加第三次确认；用户已从预览知晓成本。保存成功即更新库存、效果与战场；动画不锁下一次合法用策。同手势不重复消费，不同手势可以连续用完库存。兼行预览“普通 2.50 秒 → 加急 1.79 秒”；若两者整数毫秒相同则显示“此路线无需加急”，松手整次取消，不扣卡/兵、不建队，仍可另选路线或显式取消兼行后普通派兵。精确校验用整数毫秒，不用两位小数显示值。

耗尽态仍可点看说明“获胜可选择”，不可弹商店。满仓等无效目标有原因且不扣；所有城均无效时提示“当前没有有效目标”，可取消。周到期即时更新灰态，不能播放技能但不生效。

被动为状态不是释放按钮：如“屯田 · 3 层 · 产兵 +8.57%”，点详情明确“本周每局自动，不消耗”；开局一次轻显后收纳。跨周旧局注明“仅本局继续生效”。策略库分“主动锦囊/被动兵法”，层数用可增长整数，不写成“剩余 2 张”或只做三级填充；永久资格和当周拥有分开展示。

S09 采用最多三张纵向候选卡，页首写“只选一张”；每卡独立标主动／被动、名称、实际作用、当前→领取后及到期。主动写“库存 2→3，每用扣 1”，被动写“层数 3→4，本周每局自动”，并展示递减后的实际属性。候选通常为 2 主动＋1 被动，按 D2.3 从已解锁白名单抽取；不足按实际展示，不凑重复卡。确认成功回结果摘要，没有第二份奖励，不展示名次抢选倒计时。

## B7. 结果、周榜和异常文案

| 情况 | 标题/解释 | 主动作 |
| --- | --- | --- |
| 独立胜出 | “本局胜出”；全场仅你存活或到时城市/兵力领先 | 选择策略 |
| 最后城失守 | “本局第 N 名”；“最后一城被攻占，在途军士撤离” | 再战；次动作练兵 |
| 到时落后 | “本局第 N 名”；列各方已确定城数/兵力 | 再战 |
| 到时并列第一 | “并列第 1”；“城数与兵力相同，本局无独立冠军” | 再战；军功 0 且不升小级 |
| 全程未派兵 | 冠军注明“未有效派兵，不获军功/策略/周胜”；失败按真实名次扣分，不误写一律不计分 | 再战 |
| 玩家提前出局 | 只列个人已确定名次，电脑高位“未结算” | 即时返回，不强制观战 |
| 无本周策略 | “独立冠军可选一张策略”；说明未解锁卡需通关，不提示被动胜场门槛 | 开始对战，不警告缺卡 |
| 周榜暂无记录 | “本周还没有可显示的好友成绩” | 去对战；不伪造机器人榜 |
| 上传失败 | “本地已保存，好友榜暂未更新” | 可重试，不阻断再战 |
| 本地保存不确定 | “正在恢复本局记录，请勿重复领取” | 重试/无奖励练兵 |
| 快照过期 | 兼容正式局：“超过 24 小时不能继续，弃战扣 10 军功（最低 0）；已用锦囊不返还”，列实际前后值 | 确认弃战/返回；取消保留待处理，不可另开正式 |

周更替首页一次摘要“本周重新出发，军功与历史最高不重置”；战内只非模态提示库存到期，避免挡住派兵。设置清本地与删除本人托管分别确认，实际失败不能显示删除成功。

## B8. 动效、声音与减少动态

下表约束通用时长；逐卡视觉符号/分镜、出兵全过程和并发优先级以 G4 至 G6 为专项补充，不能用同一个光圈替代全部效果。逻辑数值与有效归属始终立即正确，保存未明确成功时不播成功施策。

| 事件 | 时长基线 | 表现与约束 |
| --- | --- | --- |
| 按下/选中 | 60 至 100ms | 描边或≤3%缩放，不移动触控区 |
| 路线变化 | ≤80ms | 跟手单线，禁止惯性追赶 |
| 派兵 | 100 至 180ms | 源点轻反馈，队伍立刻出现；不延迟扣兵 |
| 到达/兵数变化 | 100 至 160ms | 数字立即更新，短小增减；不慢慢滚真实兵数 |
| 夺城 | 220 至 320ms | 旗切换与短色彩过渡，不全屏文字 |
| 最后城受袭 | 200 至 350ms | 局部提示；同城 3 秒内不重复强提醒 |
| 主动施放/续时 | 150 至 250/100 至 180ms | 作用目标小图标；续时标 +6 秒／+4 秒；鼓令另显示新增预算 |
| 营地升级／兵种转换 | 150 至 250 ms | 权威状态先更新；保留实际扣兵、等级与新兵种，不播放免费增兵或混编 |
| 塔射命中 | 80 至 160 ms | 短箭迹与真实扣数；不依赖视觉飞行再算第二次伤害 |
| 被动开局生效 | 150 至 250ms | 最多 3 种已拥有被动的小图标轻显，层数不封三层，不逐张仪式 |
| 选策入库/强化 | 180 至 300ms | 保存后变化，数量/层数分别表示 |
| 军功/军衔变化 | 升级 200 至 350ms；扣分/降级 100 至 160ms | 数值一次即时更新；跨衔上升短换旗，下降克制说明，历史最高可查；不挡再战 |
| 页面/暂停弹层 | 150 至 220ms | 简单淡入，战斗先暂停 |
| 正常终局到可操作 | ≤600ms | 以结算已一致提交为前提；保存异常显示恢复状态，不放行不确定奖励 |

声音 7 类：点击/出兵/到达/夺城/胜/负/军令；新增军令含征兵短鼓、乡勇集合木签、火袭短火星 3 个短变体，兼行复用出兵加急变体；同类 100ms 内合并，最多 4 声音并发；背景音乐首版不必制作，不用静音时仍循环的资源。震动只用于夺城或最后城首次受袭，至少 500ms 间隔，默认关闭，可设置开启；声音默认开启但尊重设备/平台静音能力，切后台立即停。

减少动态取消缩放弹跳、位移尾迹、循环强调及镜头震动；保留即时数字、静态阵营/受袭图标和必要轻淡入。全局不使用闪屏、相机震屏或长强制庆祝。关闭音/震也能完整理解战况。

## B9. 素材清单与未来设计验收

首批设计资产：12 个营地轮廓（4 类×3 级）、4 种对应兵种基础形、5 阵营旗形、7 策略图标、8 军衔旗饰、1 共用背景、1 工作字标、约 12 功能图标、7 类短音效（军令 3 个短变体）；G7 列出复用的轻量特效素材。阵营颜色可程序换色，不制作 12×5 全套重复建筑；尺寸不同复用同源资产，避免下载整套中文字体。
