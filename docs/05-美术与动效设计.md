# 美术与动效设计

## G0. 2026-11-09 场景、字体与动效制作规格

本节配合 [04 B0 逐页设计](04-界面与交互设计.md#b0-2026-11-09-逐页场景设计)，描述目标美术与具体制作方法。设计稿不是正式 Canvas 全页实现，不把图中效果登记为手机／微信验收。当前实现与本轮验证统一见 10；以下不改变规则、节点、卡片、存档或命中区域。

### G0.1 字体与材质

字体分工固定，不能通过全站加粗或把所有字换成书法体解决风格问题。

| 用途 | 375px 基准 | 字形与排法 | 窄屏及回退 |
| --- | --- | --- | --- |
| 首页游戏名 | 48–54px，行高 1.25 | 楷书题字，暖白，轻微笔画墨损仅限题字 | 320px 用 40–46px，不拉伸中文字形 |
| 内页题名 | 27–29px，行高 1.3 | 文楷，中等字重，字距 0.05em | 320px 至少 24px；四字以上优先留宽 |
| 主按钮 | 20–24px，行高 1.25 | 文楷；朱漆面上暖白字；出征可 30–34px | 不通过长字距挤掉按钮边缘 |
| 章名／设置项／卡名 | 17–21px，行高 1.4 | 文楷；字印只作辅助，不代替完整卡名 | 4 字卡名可两行，不能截断解锁含义 |
| 规则、错误、后果说明 | 14–16px，行高 1.7–1.8 | 系统清晰正文；长规则可用宋体备选，但必须逐设备读图 | 不低于 14px，不刻意做旧，不叠密集纹理 |
| 提示与辅助 | 12–13px，行高 1.6 | 系统正文；深纸上墨字、暗木上浅绢字 | 关键条件不放进 11px 辅助字 |
| 倒计时／军功／准确人数 | 30／26–32／16px | 直立、等宽数字；兵数保留现有 CAMP_COUNT_FONT | 10→9 不缩框，长数允许展开精确值 |
| 营地等级 | 11px 常驻 | “一级／二级／三级”明确文字，沿用牌签空间 | 不以星星、颜色或建筑大小独自承担等级 |

设计稿采用本地 [LXGW WenKai TC 文楷样本](https://github.com/lxgw/LxgwWenKaiTC)，覆盖本稿简体文案；其传统部件写法作为本轮复古字形选择，正文不做繁体转换。通过 Google Fonts 官方分发接口取得 4 段字集文件，共 389,288 字节，按原样保存，不改字形或内部名称；来源 URL 与 SHA-256 在设计目录 fonts/manifest.json，完整 OFL 随附。预览只从本地加载字体，不在运行时访问 CDN。若后续自行制作衍生字库，须保留版权与 OFL 并按保留名称要求更名，不将整套大字库塞入微信包。正式微信字体加载、缺字回退与真机字形仍要单独接入／验收；未接入前继续系统楷体→宋体→serif 回退。不要宣称目前安卓和微信已统一为同一字体。

颜色取材而非逐页各造一色：深木 #251C16、旧绢 #E8D3AD、墨 #35271E、铜 #B28B52、朱漆 #8E3726、旗青 #286C5C。阵营色继续来自正式绘制层，不被朱漆按钮色覆盖。正文底色局部压平，纹理不穿过细字；量产验收需在实际合成背景上检查普通正文 4.5:1 对比度，设计色值本身不等于通过。

按钮为略有磨损的实物牌，朱漆主动作切角、木签次动作直边；每个按钮最多一道结构边和一道微弱落影，取消金边套金边。按下仅下压 1px／亮度微变，不晃动相邻文字。返回采用“‹ 返回”细木签，44px 触区；确认弹框以取消／明确动作收束，不放高亮孤立叉。设置开关两印位有清楚开关文字，不用现代 iOS 胶囊，也不让用户猜盖印等于开启还是关闭。

三张新底图由内置 imagegen 制作，仅为设计资产，路径为 artifacts/ui-direction-v2/page-design/scenes；完整提示词在同目录 image-prompts.json。文字和按钮实时排版，底图没有烘焙名称、道路或玩法信息。手册演示与正式战场同源建筑、牌签和军士，不能为了“讲解清楚”退回现代几何小房子。图示放大可以更清楚地看器物，但不能用另一套建筑等级。

统一光源为左上冷天光／侧前暖灯，主体落影往右下。主物件比背景高一档对比度，重要文本再高一档；每页只保留一处暖光焦点。纸张不得盖满所有页面，木框不得成为所有内容的容器。画片取景避免压纸石、灯火或墨砚压到标题、开关、正文。

地图仍由 MAPS 和存档实际坐标决定，不另绘一张“更好看但不相连”的假地图。战前、教学图、战场均引用相同源，六图 42 个节点 ID 不改。v1.5 保留原布局／直达及旧版标记。

| --- | --- | --- |
| L01 第一次夺城 | 暖夯土，三营形成清楚的单一路径 | 指引只指真实相邻城；最先看懂派半、守半 |
| L02 塔营与升级 | 冷灰地、弓营靶场、塔营高轮廓 | 塔射范围演示不冒充实际新地形；等级与升级箭头清楚 |

道路由不规则土边、压实路心、双车辙构成。中心线／端点／到达半径仍依据正式几何；边缘毛糙只作视觉，不能画明显弯道却让队首走直线穿山。路宽参考当前约 10–14px 土边、5–7px 路心，跨水处必须对应真实道路才画木桥。山石与树丛避开城脚、升级入口、道路和数字，不添加阻挡／高地加成。选路只叠低亮细线和一个方向标记，不能将所有道路常亮成电路板。

### G0.4 十二营地、等级与四军

等级形成双重证据：建筑轮廓＋常驻汉字牌；颜色只是辅助。当前建筑美术体量预算一级 40×34、二级 54×46、三级 66×56，落脚点不变；驻军牌在同一位置，不能建筑变大把牌推到另一个道路上。三级牌写“三级”，满级不继续显示升级箭头。营地不用新旗杆遮住战场，归属依屋顶色及牌签色边；军团继续有队旗。

| 兵种 | 一级／二级／三级的轮廓递进 | 行军识别与动作 |
| --- | --- | --- |
| 步兵营／步兵 | 低木栅＋单营房 → 门楼院 → 双塔厚院；盾矛器具在前沿 | 长矛＋盾、甲裙；六帧抬腿落脚，盾矛轻随动，不漂移队首 |
| 弓营／弓兵 | 小靶场 → 双靶廊院 → 分层箭楼院；圆靶与弓架不丢 | 长弓、箭囊轮廓；行进步态与一次真实齐射抬弓区分 |
| 骑营／骑兵 | 小马棚 → 有围场的马厩 → 双楼大马院；马匹／缰具可辨 | 骑手与马腹留空，六帧交替落蹄；速度只取真实行军值 |
| 塔营／守备兵 | 单木石塔 → 双层瞭望塔 → 高层厚基塔；以高度辨别 | 厚盾短械，与弓兵轮廓明确区分；塔楼朝向目标，楼体不旋转 |

灰度检查仍能凭器物、轮廓、旗纹、等级文字辨别；不得仅用四种颜色代替兵种。教学、军图、卡册与实际战场复用同一素材源窗，图鉴可放大器物，不另造迷你玩具兵。四兵种原六帧不改为静态图漂移；减少动态关闭步态但保留队首按真实位置移动。

### G0.5 战斗、行军与施策分镜

以下时长沿用当前 G4–G6，单位为**游戏毫秒**；本轮细化画面，不更改行军、伤害或策略时长。结构为动作起因 → 局部接触 → 收束，真实数字在结算时即时更新，不等动画。

| 事件 | 起始与过程 | 收束／减少动态 |
| --- | --- | --- |
| 按住／选路 | 源城低亮轮廓；仅真实邻路显示路线；目标轮廓和底栏同步派／留／ETA | 松手无效 80ms 内撤掉装饰，不派兵不扣卡；减少动态仍显示路线 |
| 出征 450ms | 0ms 实际扣兵并生成队伍，源城一次细尘，队旗沿真实方向轻摆；队首即刻前行 | 尘尾淡去，数字保持；减少动态静态方向及真实移动 |
| 行军 | 步态取累计实际距离；骑兵腿与马身配合，队旗布动但数字不摆；后随小人按预算 | 不能绕假弯、起步缓动或加速冲刺改变 ETA；拥挤删尾迹不删队首 |
| 友援 550ms | 从真实来向向营门收拢，同营牌即时增加实际接收数，超容部分不造人 | 存活者按目标兵种归队；减少动态只示实际增量与新兵种 |
| 交战 550ms | 0–120ms 兵刃朝门接近；120–280ms 小范围一次接触亮点与尘；280–550ms 回落 | 未占领不播成功印；减少动态静态接触＋真实剩余数，无镜头震动 |
| 夺城 800ms | 0ms 归属／兵数即时变；前 550ms 保留接触，180ms 起城脚新归属印展开 | 新城立刻可操作，不等旗展；减少动态即时归属牌＋接触标记 |
| 塔射／齐射 300ms | 从真实发射源到真实命中位置的短箭迹；弓兵轻抬最多 2px；真实伤害即时扣数 | 清零不换主；无正伤害不播命中；减少动态保留短方向与扣数 |
| 升级 150–250ms | 原子保存成功后真实等级立即替换，局部木构添层和实际消耗提示 | 不中断塔射节拍，不补满驻军；减少动态新建筑和中文等级直接呈现 |
| 征兵首次 600ms／续时 280ms | 营旁战鼓敲一次，小环刻线回收；持续态是鼓令标记和真实剩余时长 | 不是立刻送 8 兵，增募仍走生产与额度；减少动态静态鼓记 |
| 兼行随出征 | 准备时令签朱印；合法且确实更快的派兵成功才消耗。出发短双箭，行军细尘尾 | 无有效派兵不播军令成功，不先扣卡；减少动态双箭＋真实移动 |
| 乡勇 600ms | 人影从城边收拢，实际 +N，48/50 只显示 +2；满员不虚构补兵 | 不把人影计成额外在途军；减少动态只示实际增量 |
| 火袭首次 600ms／续时 280ms | 目标粮袋一缕短烟与小火星，深色横杠标“停产”，塔同步停射 | 不烧整座城、不造成驻军伤害；减少动态停产文字与剩余时长 |
| 被动领取／开局 | 屯田添一束谷穗、神速马蹄短刻线、扩营添一段栅栏，各自实际层数／增益 | 不给三种被动共用一团金光；静态模式直接显示新值 |
| 淘汰撤离 160ms | 已显示在途队留下弱残影；从规则立即失效 | 残影无数字、无攻击、不可点击；减少动态直接移除 |

同城并发优先级：末城危险／夺城与交战 → 策略成功 → 普通增兵。持久停产／鼓令不能被新粒子盖掉。同一事件按 matchId＋eventId 去重，读档不重播成功；保存失败不盖成功印。全局最多 80 装饰粒子，超过 40 在途队先去烟、尘、尾迹和装饰兵，保留准确数字、所有真实队首和关键状态。普通暂停连同特效冻结；恢复不追播离线特效。

### G0.6 页内动效、声音与资源实施

页面过渡只作用于主物件，背景不全屏推拉：取令 160ms、绢册淡入 160ms、章签切换 120ms、按下 60–90ms、设置印位 100ms。默认图解静止，点演示后播放一次并停在结果。减少动态不保留纸页翻转、摇旗、尘光循环或物件抬升；必要状态和真实部队移动保留。不会因为少了动画而少一项操作说明。

声音沿用现有短音类别：操作木声、出征号令、碰撞、塔弦、军令、胜负；同类合并、最多 4 并发、后台停声、恢复去重、设置静音与试听均不变。不新增循环背景战鼓。震动继续遵守默认关、500ms 限频及既有事件边界，不把每次点按钮变成震动。当前手机无声问题仍待真机定位，设计稿静音，不能当作音频已修复。

正式接入时先做资产置换而不是追加所有母版：新场景候选压到约 550×1100 的 JPG，目标单张 80–120KiB；具体质量和总量必须实际测量。三张母图、字体母版与本独立设计稿不在 ART_SOURCES，不进入微信构建。现有 4MiB 门禁和至少 512KiB 余量检查保持，设计预算不能据此承诺能全部塞入；若不足，先重用场景局部和减少新纹理，再逐张验证，不牺牲营地／军士辨识。字体仅做有限字集样本，正式子集必须覆盖实际动态文案、字库许可、缺字回退和平台载入失败。

逐页交付证据需包含：普通／减少动态／灰度静态图，320／375／430 的实际排版，功能和失败边界自动测试，桌面实际点击／回来源；战场另记录同场景 draw p95 与帧间隔。桌面预览只能证明桌面结果，微信安全区、真机听音、触觉与性能保持待验。

### G2.3 为什么不直接堆名计

首版不用“空城计”包装无敌、不用“借东风”包装魔法、不用“火烧连营”包装只有单城停产的效果。当前没有情报迷雾、风向、火焰蔓延或真实欺骗选择，名称不能暗示这些不存在的规则。“火袭粮营”是一座营地的生产受扰，塔营还会被短时压制射击，粮袋是状态符号，不是第七种城或可管理的粮草资源。

## G4. 每种策略的动效分镜

### G4.1 共用时序，不共用同一种特效

准备态只显示卡选中、合法目标边线和效果/成本预览，不播施策成功音、不扣卡。火袭目标为敌城；其余目标规则按 D，不能因为地面有图案就自动施放。

主动成功时间零点是该次事务**已提交的权威效果状态可展示时**；库存、驻军/生产/期限/队伍同一状态立即正确。不能先播成功再赌保存会成功；超过 E 规定等待阈值时显示记录状态，失败/不确定进入恢复流程。UI 所见剩余时间取真实游戏截止时间，不从动画结束重新起算 6 秒或 4 秒。

时长是表现基线：入场 150 至 250ms，续时 100 至 180ms，退出 80 至 120ms。暂停冻结战场游戏时钟及其特效；页面过渡可使用独立 UI 时钟。缓动以短 ease-out 为主，无大幅弹跳，无全屏“计策发动”。以下“脉冲”指一次低对比描边扩展，不是闪白或持续闪烁。

加速不能造假：某短路受 1000ms 最短旅时或 48 速度上限限制，兼行可能不缩短实际 ETA。按 D 比较同状态不用/用此卡的整数毫秒；无收益显示“此路线无需加急”，整次取消、不扣卡/兵、不建队、不播成功，保留准备可另选路线或显式取消后普通派兵。神速／出征兵种的已有加成照实计算，不为视觉速度改变上限或最短旅时。

本地撤离只对上一帧已显示、淘汰时仍在途且未被击毁的队首生成固定位置残影；观察缓存和残影各最多 40 个，从低透明度在 160 游戏 ms 内淡出。残影不带数量、查询或攻击能力，不进入存档。普通暂停冻结阶段，读档／换局清空；减少动态、超过 40 队及终局不保留残影。未显示过的队伍直接按规则移除，不补造动画。

本地射击姿态持续 300 游戏 ms：塔营仅将楼内箭杆朝向事件记录的命中位置，不旋转楼体；正伤害齐射仅将该队队首的弓弦轻抬最多 2 px，150 ms 达峰后复位。减少动态保留静态姿态，超过 40 队省略抬弓；暂停随游戏时间冻结，重建画面不重播旧姿态，伤害与旅时始终由规则决定。

弓兵按主文档第 3.1 节制作一次行军齐射，F00 至 F11 编号保持，新增 F12。多队同刻对同城射击可合并箭束与实际总扣数，但各队已射／已跳过状态分别正确；截零溢出不表现成额外伤亡。准备时间是规则，抬弓动画不额外加等待。攻城营及其部队不进入首发清单。

### G5.1 队列的“兵多”感不牺牲可读性

装饰数量基线：1 至 4 兵画 1 人，5 至 9 画 2 人，10 至 19 画 3 人，20 至 39 画 4 人，40 及以上画 5 人；拥挤／低性能时可降到 1 个队首标记，不改兵力与事件。所有兵团仍有可辨识的队首／阵营。标签按队伍 ID 保留稳定相对偏移，仅在约 40 px 邻域避让，不整图寻找远处空位；冲突优先当前手势相关、临近到达、最后城来袭。暂停页“查看行军”分页查询每队实际人数、旗形、兵种和目标，不能画假合并总数；查询及目标详情始终冻结，明确继续后才恢复战斗。

行军进度 p=clamp((当前游戏毫秒−departAt)/(arriveAt−departAt),0,1)。队首由源/目标边缘半径 18 之间插值；尾部小人只是装饰，不能因为尾巴尚在路上延迟到达。F02 源点反馈与 F03 同时进行，F04/F05 到达反馈在逻辑结算后发生。兼行用权威 arriveAt，不为了“更帅”另写一套缓入缓出位移。

选路箭头、步态、短尾迹只表达规则，不额外增加路径绕行、阵型加成或兵种克制。塔射范围来自主文档，扩营饰件和等级外观不改变逻辑端点半径 18 或箭塔射程。

### G5.2 不把连用和恢复做成重复奖励

- 每个已接受动作/战斗事件有独立事件标识；表现去重键用 matchId＋eventId，不只用 cardId。两次独立乡勇必须各自消费/实际加兵，重复回调不得重播为两次成功。
- 连续同类实际增量可在 100 ms 内合并一个视觉“+合计实际数”，但不能合并逻辑事务、额外扣卡或忽略容量。例如无扩营的二级营地 48／90 先 +6 再 +6，标签可显示 +12；不是无视每次确认校验。
- 暂停/后台冻结战场动画与模拟，音效停；恢复不补算离线战斗。返回后队伍根据快照当前位置继续，持久状态按真实剩余期限重建，不从起点重飞、不重扣卡、不重播整套施策/领取/晋升音。
- 显式重新读取或恢复备份时，即使对局 ID 不变，也清空此前的瞬态反馈与事件去重缓存；回退后重新产生的同编号事件应按新权威状态展示。普通暂停／继续保留游戏时钟上的剩余表现，不当作存档重建。
- 保存失败不播成功；未知结果恢复后以已提交状态为准。不得靠动画完成回调发卡、产兵、宣布胜负或执行周清。
- 终局取消未接受手势，停用卡/派兵；正常提交完成后仍须在 B 规定 600ms 内可操作结果主动作，不等所有烟尘播放完。

## G6. 层级、并发、声音与减少动态

### G6.1 战场层级与克制原则

从后到前：低对比背景 → 路线/尘线 → 城体/军士 → 短时局部特效 → 关键旗标/兵数/目标边线/停产状态 → 页面 UI。短时烟火不能盖关键读数，也不截获触摸；同一位置有效归属始终只有一个。

夺城、补兵等瞬态浮字须避开相邻营地的升级入口、兵数、真实危险及鼓令／停产状态，也避开其他浮字与队首；移位后用短细线指向对应营地。地图不常驻“末城”文字，真实己方末城遇袭才提示。空间不足可省略冗余装饰，保留即时归属、驻军、持久状态和队首；未显示的行军人数可通过暂停军情精确查询，不能虚假合并。行军标签仅局部避让，禁止用长引线跨地图悬挂数字。

弓兵与其他兵种同样只显示小旗和精确兵数，不常驻“待／射／跳”文字；抬弓与箭束解释真实齐射，查询保留完整状态和跳过原因。

同城同时最多一个瞬态强调序列；成功攻城的到达与换旗合为同一序列，前 550 游戏 ms 保留接触冲击、180 游戏 ms 起展开夺城印记，总时长 800 游戏 ms，归属和兵数即时更新。减少动态显示静态接触与归属，不移动镜头。新的高优先级事件可替换/收束旧表现：最后城威胁/夺城与交战 > 策略成功 > 常规增兵。被替换的是装饰，不是效果或提示；鼓令/停产等持久状态仍保留。每城两种持续主动足够容纳，不为叠卡堆十层光圈。

火袭用小面积暖橙火星、深色停产横杠和烟形，不能把电脑甲朱色阵营变成所有火袭目标的旗色；关音/灰度/减少动态时也靠图形和“停产”读懂。不同阵营只改现有 B 色与旗形，七策略不再各占一种高亮主色。

仍按 F 预算：全场粒子最多 80，声音最多 4 个并发；压力下先去尾迹/烟尘/步态，再减少装饰军士，不丢输入、兵数、旗标、停产或队首，不删逻辑兵团。256 队伍是压力测试规模，不是玩法上限。30FPS 目标和真实触摸延迟必须以后实测。

本地实现以超过 40 支在途队伍触发拥挤降级：兼行尾迹、步态、施策烟点和装饰小人收束，施策保留静态图标；每支真实军团仍按实际位置绘制队首和旗标。回落到 40 队以内后，按当前游戏状态恢复常规表现，不补播已过期事件。

### G6.2 声音与震动

首页以原青瓦城关图为场景底图，在文字与触区下方叠加缓慢云气、少量叶片和城门暖光，按钮位置与命中区域不随动画移动。减少动态显示稳定画面。该动效不修改对战速度，也不能代替行军／交战反馈的实际检查。

声音开启后的首次触摸须等待音频恢复完成再发出点击声；恢复期间已提交的战斗短音也等待恢复，不因恢复尚未结束直接丢弃。切后台、静音或暂停清除尚未播放的声音，换局或重新载入丢弃旧局待播事件。声音失败给出简短提示，设置提供独立 240 ms 短音“试听”重试，不受触摸点击声合并影响，不能长期静默失败或强制覆盖用户声音／减少动态开关。

7 类短音效与 B 一致：点击、出兵、到达、夺城、胜、负、军令。军令新增 3 个短变体：征兵短鼓、乡勇集合木签、火袭短火星；兼行沿用出兵声加急变体（如缩短尾音），不用另播两声。到达类增加友军收队／敌军兵刃／塔射短弦变体，齐射复用短弦的一次箭束变体，军令类可增加升级短木构变体；同一次夺城有成功号令时省掉低优先级碰撞声。

同类 100ms 内合并，最多 4 并发，重要夺城/终局优先于普通到达／齐射；同一个事件不因重绘又播放。选卡仅点击声，保存明确成功才施策声。声音短促、不循环战鼓/燃烧；默认不开背景乐制作任务。后续需记录自制/授权来源，不拿竞品音效。

震动继续仅夺城或最后城首次受袭、默认关且至少间隔 500ms；不额外给四策略和每支出兵震动。设备静音/关闭声音/关闭震动均不损失信息。

### G6.3 减少动态的对应替代

| 常规表现 | 减少动态模式 |
| --- | --- |
| 鼓令回弹/谷点添入/营栅轻展 | 图标和数值静态更新，最多 80 至 120ms 低对比淡入 |
| 兼行尾迹/步态/源旗摆动 | 保留队首按实际位置移动与静态双箭，不显示装饰摆动或尾迹 |
| 火星与小烟团 | 直接显示“停产”静态粮袋/横杠及剩余秒数 |
| 归队/交战尘团/夺城展开 | 即时兵数/归属改变，可用短淡入，不移动镜头 |
| 弓兵抬弓／箭束 | 静态射击方向与目的营地实际扣数，保留队首正常移动；已射／跳过状态按需查询 |
| 跨衔旗饰展开/降级提示 | 直接展示实际军功与当前新衔；只有上升写“晋升”，下降写“当前军衔调整” |

必要的队首移动不是可删除的装饰，否则玩家无法判断行军；可以关步态而不能让兵团从出发点瞬移到目的地。所有模式均禁止频闪、全屏白闪、相机震动、长强制庆祝。

## G7. 制作资产与验收顺序

复用 B9 的 12 个营地轮廓、5 旗形、7 策略图标、8 军衔旗饰；四类小兵使用手绘六帧动作图集，图片不可用时保留 Canvas 小步态，不增武将立绘、骨骼动画或未启用的攻城兵资产。火苗／烟／尘／短箭／鼓刻线使用少量共享形状，停产符号可复用卡图。纹理预算和字体方案仍以 F／B 为准。

本轮已获授权的制作顺序：

1. **先做一个战场小样**：普通与兼行派兵、到达整编、敌军交战、夺城、固定塔射、弓兵单次齐射、驻兵升级，验证兵数/归属即时可读和操作手感；不是先做长首页片头。
2. 接四主动准备/合法/无效/续时/易主/保存异常状态，确认每策“看图能说出作用”，尤其即时+兵与持续征募、停产与伤害的区别。
3. 接三被动开局／累计强化／跨周，军衔普通升小级/跨衔与扣分降级；最后接结果页和声音。
4. 按 B 三种屏幕尺寸以及 H01 至 H18、N41 至 N70、U/F 用例验常规、拥挤、减少动态、静音、暂停/恢复。独立记录真实观感，不把分镜条目数当满意度。

Figma 适合表达关键帧、页面层级与短过渡；任意路径跟手、同刻多方结算、连续用策与存档恢复的正确性必须以后在实际游戏实现验证，不声称连好原型就验过引擎行为。

本轮直接完善原创 Canvas 绘制与运行反馈，不购买素材，不用生成图片／视频代替实际战斗。主题／名词／分镜是规格，运行截图与交互检查仍须独立取得；真机和系统性平衡测试继续保留。

### 战场样板体验细化

四兵种六帧按实际行进距离推进，普通速度 24 时约 720 ms 一周期，加速时步频随位移变化，各队与队内适度错步；减少动态及拥挤保留静止姿态的真实队首移动。兵数牌优先队首侧上方，控制牌边与队首的间距，无法避让时保留队旗与逐队查询，不把数字挂到远处。 齐射、升级等临时回执先尝试目标城池上沿及两侧空位，避免上沿中央被军队牌占用后立即漂到另一条战线；真实兵数牌保持优先。

三张正式地图在不改变点位、连通、旅时与塔射的前提下，增加自然边缘院落与中心石坪；A01 草地土坪、A02 冷灰冻土和雪痕、A03 暖砂石与细裂纹按底图配色，装饰均为平面，不形成通路障碍。木栅营、门楼院、双塔堡在小屏保持可辨体量，旗与等级靠近建筑；不增加无规则依据的阻挡地形。

## G8. 十策目标组合：图标、军令卡与逐策动效规格

2026-11-04，承接用户确认的 [H0 十策方向](09-策略储备.md)。本节是新制作规格，现行 G2 七策和已实现表现继续有效；10 张 SVG 母稿与交互分镜存于 [设计资产](../artifacts/strategy-design-v1/index.html)。新主动与招抚尚未进入游戏；这些设计预览不作为规则或真机验收证据。扩营原卡与资源保留，不把旧资产覆盖成招抚。

### G8.1 图标与卡面共用的视觉规则


**古战场画风约束（2026-11-04 用户明确要求）**：十策必须融入已有汉末军阵，而不是另做一套现代图标皮肤。正式美术以 `warfront-ground.jpg` 的夯土、`warfront-camps.png` 的灰瓦木栅营地和现有军士为同源参照；卡面沿用城关旧绢、深木横档、少量磨旧铜饰。图标以手绘器物体积、木纹、绳结、鼓皮、粗布和低饱和烟火表达，不能用大块几何简笔画代替正式古战场素材。SVG只作为轮廓母稿、灰态／异常回退和小尺寸检查，不是正式扁平视觉方案。

预览现已复用上述地面、营地和军士实际素材，并在主策略入口使用手绘概念板格位，木绢框配合土路／双车辙，不再以横线纸背景、几何房屋和方块人代表最终风格。格位仅供设计预览，正式素材仍需独立透明编码与质量核验；概念板不直接作为生产图集。两张会攻小旗是军令意象，正式资产不得把双色误画为敌我混队，阵营信息继续由实际旗形／驻军牌表达。

动效同样受背景约束：征兵是敲鼓应令，求援是小烽火和传令，齐攻是双路军令，拒马是木梁和绳结，乡勇／招抚是营门集合／安民；粒子限局部土尘、木屑、小火星和薄烟，禁止能量波、魔法罩、霓虹尾迹和全屏爆炸。状态与兵数要清晰，但不得把战场做成现代数据面板；说明文字可用旧绢短签，所有装饰仍不改变规则或阻挡触摸。

- **主题**：汉末军令器物，深木线、麻绳、皮革、灰砖、旧铜与少量青布、朱漆；阴影只说明体积。没有人物肖像、神兽、悬浮宝石、光圈、稀有度金框。器物是玩法意象，不宣称文物复原。
- **两档资产**：SVG 母稿 viewBox 96×96，透明底，图形完整落在 6 至 90 范围；未来导出 96／192px RGBA PNG，以 44×44 触区内约 32px 图形与 72px 图鉴图形检查。当前母稿是独立设计源，正式 Canvas／微信若接入需 PNG 图集或复用绘制函数，不直接依赖 SVG 解码。图鉴的大卡可以添一处同源营地，但小图标不画全景。
- **形状优先**：每张一个主轮廓、最多两个辅助部件，主线在 96 母稿约 2.6px；32px 下保留主轮廓，不靠缝线、眼睛或细字认卡。兼行是令旗／双箭，神速是足迹；火袭是粮袋／烟火，求援是方形烽台／汇入箭；乡勇是集合人形，招抚是开门／安民粮囊。
- **色与状态**：器物色不表示阵营；红橙仅限鼓木／小火星，不给十张各分配一种强色。阵营仍由真实旗形／颜色表示。选中用朱砂勾角＋实线边，不发光；未解锁用同轮廓灰材质＋锁形；已解锁库存为 0 保留正常图形，以“0”和不可施放提示区分锁定。图鉴仍不显示个人库存。
- **文字由程序绘制**：图像不烘焙名称、数字、层数、期限、锁和短标。主动固定“主动”签、被动固定“被动”签；领取数量和升级价格不能当图标主体。数量角标、底部短标和图形安全区分开，最小有效触区 44×44。
- **使用与预算**：先复用现有军令卡框和效果图形。SVG 母稿不进入运行包；位图若采用目标为单个不超过 256 KiB 的十策图集，需测实际解码／缩小表现并通过既有微信 4 MiB 门禁，不能将高分辨率概念板整张打包。图片异常继续用共享 Canvas 器物轮廓，不删除策略入口。
