# 平衡与测试计划

更新：2026-09-10。v1.4。本文区分已确认规则、未实测参数与待定设计；没有运行游戏、统计胜率／留存或验证性能。

## F1. 本轮变化与代价

| 变化 | 目的 | 必须检验的代价 |
| --- | --- | --- |
| 冠军混合只选一张 | 减少结算步骤、严格发卡，不必等待淘汰者轮选 | 主动供给减少，可能更舍不得用 |
| 被动按获卡累加，无里程碑／总层上限 | 每次选被动都能积累本周打法 | 周初偏选被动、长期优势；用递减曲线检验，不暗加满层限制 |
| 通关解锁候选资格 | 逐步理解策略，不靠一开始堆七卡 | 解锁不等于拥有，必须讲清；不能锁地图建筑使用权 |
| 单营单兵种、到达转换 | 单个驻军数字、整编路线有价值 | 免费转换可能令高产步兵营＋骑营形成唯一解 |
| 人数达标、消耗驻兵升级 | 留兵建设与当前出兵之间取舍 | 升级回本过快会滚雪球，过慢会没人点 |
| 塔营覆盖路过军队与敌营驻军 | 从单点防守变成区域控制 | 塔群封路、打空邻营、屯兵拖满时间；地图必须重测 |
| 弓营独立、攻城营储备 | 兵种／建筑职能更清楚 | 移动远程机制未定，不能把全部内容写成开发就绪 |

军功、最后城判负、240 秒裁决、本地保存、官方好友榜例外保持。范围增加已使其比单一数字夺城复杂，个人开发应按检查点验证，不一次制作全部兵种与特效。

## F2. 营地、整编与升级的纸面推导

以主文档测试表为准，以下只算理论值，不是实际收益保证：

- 无被动步兵营一级产速 1.2，二级 1.56，升级多 0.36／秒；消耗 10 人的静态回本约 27.78 秒。二升三多 0.36，消耗 25 的静态回本约 69.44 秒。满仓、失城、停产会改变结果。
- 一级塔营到二级仅多产 0.12／秒，10 人静态产能回本约 83.33 秒，但还提高射频；不能只用产兵回本评估塔营。
- 路长 200 的步兵／骑兵分别 2500／1786 ms，相差约 714 ms。中转须先抵达转换，再按半数派兵；不是同一批兵无成本全数瞬移到骑营再出击。
- 40 人连续半数出兵为 20＋10，普通操作可转移 30；H 金蝉一次 32 的独特价值仍待证，不自动优先开发。
- 箭塔单次 1 人、一级间隔 2 秒，只决定射击节拍，不保证每支队都损失相同人数。出生节拍、路线、优先目标、压制、升级、同刻易主都会改变命中。
- “满 30 人自动升级、出兵又降级”与“无成本用同一队升级所有城”均不是当前规则。升级扣人且保留等级，双方易主共享已建成设施。
- 弓兵基础转换样例按 1∶1，暂不具有完整移动远程优势，不能据此做四类建筑最终平衡结论。

## F3. 奖励与被动累加账

一个冠军只对应一次混合选择、只领取一个策略单位。设领取的主动总张数为 A，被动累计层数为 P，已放弃／未领数为 U，则同周正常情况下 A+P+U=有效冠军次数；消费后的剩余主动库存不能代替 A 计算。没有额外被动里程碑奖。

| 有效冠军次数 | 总选择次数 | 全选主动 | 全选同名被动 |
| --- | ---: | ---: | ---: |
| 0 | 0 | 0 张 | 0 层 |
| 1 | 1 | 1 张 | 1 层 |
| 4 | 4 | 4 张 | 4 层 |
| 8 | 8 | 8 张 | 8 层 |
| 12 | 12 | 12 张 | 12 层 |

末列是假设每次所需同名卡均进入候选并选中，不是保证定向获得。七卡全部解锁时，候选固定为 2 主动＋1 被动，具体按 D2.3；同名重复不排除，无三层封顶。

若假设每局独立胜率 p 固定，且每次都选择主动，平均每局新获主动为 p 张；p=25%／40%／50% 时分别 0.25／0.40／0.50。前五局无胜概率为 (1−p)^5，约 23.73%／7.78%／3.13%。实际学习、周构筑和电脑会改变 p，不据此承诺首胜时间。

递减函数 B(c,n)=c×n／(n+4)：当 c=20%，n=1／3／10 为约 4%／8.57%／14.29%，单项始终小于 20%，但各类成长及建筑等级仍可能形成组合优势。容量取整可能让个别重复卡没有即时多一个兵位，选卡必须预览，不能假称每张都有相同可感知收益。

周初长期被动更有吸引力、临近周末主动更有吸引力，是设计取舍，不是已经达到等价。不得用隐藏掉率、里程碑、赠卡或装备上限掩盖失衡。

### F3.1 胜负军功是否更合适

比每局参与就升级，更符合用户希望的胜负意义，也让争取第二名而非早退有价值；代价是从轻松履历转向有损失的成长。军功不加战斗属性/卡奖励、不用于匹配，避免输分又削弱战力的双重惩罚。

应计军功为第 1/2/3/4：+30/−5/−8/−10，平列第一 0，弃战−10，实际遵守 0 下限。一次胜利的+30 等于三次第 4 的最大扣分；不存在连败加罚或保级广告。教程与练习不计分且可反复练手。

- 若四个名次各 25%，远离 0 下限的每局期望变化=(30−5−8−10)/4=+1.75 军功，约 17.14 局/30 分只是平均量级，不是晋级所需局数承诺。
- 若胜率 40%，其余三名在败局中等概率，则期望 30×0.4−(23/3)×0.6=+7.4；约 4.05 局/30 分。
- 若每次失败都第 4，期望 40p−10，胜率低于 25%时会长期趋近低分段。0 下限防负债，不能自动解决新手挫败。
- P=30 第一次授军司马后一次第 4 可能回 20/新卒；这是当前允许降衔的明确后果，不暗设军职永久保底。用历史最高纪念与免费练兵缓和，并专门观察刚晋升就降级的体验；若多数人因此不愿再战，需再提规则调整，不能宣传必然更留人。

失败不倒扣本周胜场、策略库存和被动层数；周重置只清周资源，军功与最高记录不重置。榜单仍比对电脑周冠军次数，军功不是具有反作弊保障的真人竞技评分。

### F3.2 策略与建筑互动

四主动保持救急／蓄兵／机动／压制分工。鼓令每张 6 秒、最多 8 点额外生产额度，避免高等级产能把一张放大到无限；乡勇立即最多 6 人；兼行只买真实 ETA 改善；火袭 4 秒压制生产，塔营同时停射，但不直接造成伤亡。

扩营仍作为第三首发被动，是否替换为众志、招抚或射频类须另定，不能一边保留原卡一边把替代品也算首发。完整解锁不代表全卡在任何地图都有一样强度。

### F3.3 无奖励对照顺序

以下只记录以后原型方法，不是本轮已制作或已获授权运行的实验：

1. 无卡的步兵营／骑营整编与驻兵升级，比较“立即出兵”和“留兵升级”，确认数字／成本可懂。
2. 加塔营，对照原型射程与射频参数，检查路过军队、邻营驻军、零兵不占领、塔群龟缩；保持地图初始条件一致，一次只改一项。
3. 待弓兵规则另行确认后，单独比较远程支援是否有独特价值，检查群体射击与转换套利，再加入完整四类对局。
4. 接混合奖励，记录周初／周末不同库存下主动与被动选择、主动消费率和无卡新手首胜；比较 0／1／3／10 层，以及更高层边界。
5. 有实际重复拖拽痛点时才比较免费 80% 交互；当前默认仍半数。H 新策略继续独立白名单、无奖励，不扩大正式池。

## F4. 高频风险与防线

| 风险 | 规则／测试防线 |
| --- | --- |
| 到达前转换成敌营兵种获得便宜胜利 | 先用出征类型与真实剩余兵力交战，占领后才转换 |
| 同一支骑兵带固定塔射出征 | guard 不继承建筑箭塔，兵种与建筑能力分离 |
| 多塔同时攻击顺序造成额外击杀 | 同刻快照选敌、合计伤害，溢出不转目标 |
| 塔把驻军打空就改旗判负 | 清零不改归属，必须部队抵达占领 |
| 升级／回城刷新一发免费箭 | 升级保留已排定下一发，占领后等待完整间隔 |
| 单营被动堆叠失控 | 不限张数但使用递减曲线，同类百分比相加，速度总限 160；实测仍不可省略 |
| 重启重复升级／多领被动 | actionId／choiceId 与完整状态同事务，提交点杀进程验证 |
| 旧两奖励／三层检查仍在代码中 | v1.4 用例覆盖第四／第十次被动、唯一混合选择、永久解锁不周清 |
| 转换后混编 UI 或人数多算 | 一个驻军整数，队伍到达删除，兵种变化不产生额外人数 |
| 弓兵未定却宣称玩法完成 | 主文档第 11 节设设计门槛，基础样例不得代表成品 |
| 真人公平性误承诺 | 当前为本地对电脑，不把可修改库存当可信竞技资产 |

## F5. 性能与制作预算

这些是实现验收目标，不是平台硬限额或当前性能结果。

- 实机以稳定 30fps 为最低目标、能力足够 60fps；同输入 30/60fps 结果完全一致。
- 触摸到可见选中/路线反馈目标 p95≤100ms；正常本地事务提交目标 p95≤100ms，超过 150ms 有保存状态，失败保护暂停。
- 逻辑兵团不建逐兵刚体；先用 256 同时在途兵团、9 城、全部塔射并发、升级、转换、频繁策略与同刻到达做压力用例。256 是测试规模，不是玩家出兵硬上限。
- 表现预算：每团最多 5 军士，拥挤时降为 1 旗＋数量；全场同时短粒子≤80、声音≤4，先合并视觉/音效不丢伤害或输入。
- 单个序列化存档槽目标≤256KiB、双槽合计≤512KiB；超出时先精简字段/失效实体，不截断合法库存/兵团。必须核对平台真实存储限额。
- 首屏自有美术与音频资源预算≤3MiB（不含引擎）；总首包仍须按实际微信限制检查。冷启动可操作目标≤5 秒需记录机型/网络，资源齐备后的回流目标≤2 秒。
- 连续 20 局结果/快照/粒子/音频资源可释放，内存应无单调持续上涨；后台无战斗模拟与音频播放，不轮询榜单。
- 不引入 3D、骨骼武将、逐兵物理／复杂混编动作库、大中文字体下载或第三方分析来追求表面完整度。原创资产最小清单见 B9，每项记录来源、作者、许可及修改范围。

## F6. 未来真实试玩

建议 5 名未读文档者首玩 10 分钟，另 3 名至少完成 20 局标准四方；手工匿名记录，不接统计 SDK。小样本仅用于发现问题，不证明市场留存。

| 观察项 | 首轮目标／记录内容 | 不通过时 |
| --- | --- | --- |
| 派兵与转换理解 | 至少 4／5 能解释派一半、友援转换、占领后转换，知道路过不换兵 | 修预览和短教学，不加长文 |
| 升级理解 | 能说明看本营人数、升级扣兵、不因出兵降级、被占领保留等级 | 修成本与留守显示 |
| 塔营／弓营区分 | 能说出固定塔射与可出征弓兵的区别，清零驻军不代表占领 | 修剪影、范围／命中反馈 |
| 基础首胜 | 记录前五局独胜实际分布与是否能无卡取胜 | 调地图／公开 AI，不偷偷赠卡 |
| 多条路线 | 每图至少两条路线被主动采用，不总是守塔或批量中转骑营 | 调布局、产能、射程／射频 |
| 用卡与累加 | 能解释只选一张、主动扣次、被动累计递减、永久解锁与周拥有 | 修领取预览与卡片说明 |
| 胜负成长 | 能复述胜加败扣、最低 0、当前与最高区别，记录降衔后的再战意愿 | 先修解释，再评审积分 |
| 中断／跨周 | 无误以为回首页判负、升级白扣、永久解锁周清等误解 | 修事务与文案 |
| 可读性／审美 | 三尺寸中数字、范围、兵种与按钮清楚，不以特效遮伤亡 | 缩装饰、调层级、真机复验 |
| 再玩动机 | 记录为何再开／不再开，是选择变化还是数值压制 | 根据实际反馈改规则，不保证吸引力 |
