# Change: 借墙蓄力、破印扩散与轻量局内构筑

## Status

2026-09-08：玩法提案，待用户确认。用户已认可 V6 两张战斗样板的视觉方向，但尚未批准本提案，也不等于完整 Phase A 或灰盒开工已获批准。本轮仅新增设计文档，不修改 Figma 或游戏运行时代码。

## Why

现有原型解释了“弹射、扣耐久、三回合三选一”，但没有完整定义连锁如何发生，地图缺少独特机关，灵球缺少打法差异。只有背景和数值变化，难以给玩家明确的观察目标、技巧成长和重玩理由。

本提案将核心乐趣集中为：**借一次墙，打破关键符印，让一片残血目标依次碎开；每三回合，把这个打法强化一次。** 吸引力是待验证的设计假设，不宣称已经验证留存或平衡。

## What Changes

- 保留竖屏单手、1—3 分钟普通关、耐久消除、回收/回合推进、每三回合三选一。
- 定义基础伤害 1、借普通墙后下一次物理命中额外伤害 1；蓄力不随反弹无限叠加。
- 所有符印破碎均产生可预判的局部冲击波，打掉邻近符印 1 点耐久；只有被打至零的符印继续传播，单枚符印不重复破碎。
- 普通关使用三波有限目标，清一波再出现下一波；未清空时回合末整体下压，触底失败，不使用实时倒计时催促瞄准。
- 提议三张地图，各只引入一个标志机关：月下山门的回响壁、莲灯水庭的莲心印、流云天阶的成对云门。
- 提议玉灵、月芽、云鱼各一个横向特性，不设永久攻击力、等级、装备或稀有度。每周榜固定当周灵球，未解锁者也可临时使用。
- 定义六种两级奇遇、明确的候选规则、主/子球边界与最多 8 球的演出预算。
- 计分奖励实际破印、单回合连破和通关效率，不奖励空弹、墙碰撞次数或等待时间。
- 更新规则口径：原 V5“连锁回响”从“提供连锁”改为“强化已有破印脉冲”；云鱼解锁从旧画稿“三次每周挑战”的示例改为普通章节解锁，避免等待三周。以上是提案，尚未应用到画稿。

## Impact

- Affected specs：新增 `battle-rules`，作为 `define-dandan-qijing-product-baseline` 的玩法细化，不复制或覆盖其产品定位、存储、平台和阶段门禁。
- 现有基线尚在 `openspec/changes/`，`openspec/specs/` 为空，因此本提案使用 ADDED Requirements；实施前先协调基线归档/合并顺序，避免双份规则。
- Affected design：批准后需补齐 V6 的借墙提示、破印范围、下压预警、三波进度、奇遇文案、灵球特性、地图机关和周榜同开局说明。
- Affected future code：未来独立灰盒的碰撞/伤害事件、波次/回合、能力、配置、演出预算与计分；本次不创建这些实现。
- 约束不变：核心配置与进度本地保存；仅微信官方托管数据与开放数据域支持好友周榜；不新增账号、服务器、完整云存档、分析 SDK、体力或广告复活。

## Approval requested

确认“借墙蓄力 + 基础破印扩散 + 三种地图机关 + 灵球单特性”是否作为下一版规则方向。文档中的数字是首轮测试参数，不是已平衡的上线值。批准玩法提案后先完成设计验证；进入 Cocos 仍需另外通过完整 Phase A 验收。
