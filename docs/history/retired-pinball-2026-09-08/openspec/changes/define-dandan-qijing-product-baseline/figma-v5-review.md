## 这轮改变

保留夜游山水与玉灵角色，重新组织首屏和战场。首页只保留一个黄色主行动与两个安静的二级入口；战斗去掉密集棋盘和中央大字遮挡，使用青色玩家/轨迹、黄色符印/主要按钮、红色危险。能力选择以三条整行选项呈现，不堆叠复杂卡牌框。

玩法按已批准的产品基线：反弹命中有耐久的符印、数字归零消除、连锁扩散，每三回合一次三选一。不采用后续试稿中出现的“命中同类消除”规则。能力文案和演出细节是待评审的设计建议，不等于新的数值规则已获批准。

操作按钮、信息行、开关使用组件变体；颜色与间距复用现有变量，避免每页自行定义。字体统一为 Noto Sans SC。

## 怎样体验

在 Figma 中选择首页画板后点击 Present/播放，选择「01 · 首次完整体验」。从“开始弹射”进入；教学与瞄准阶段拖动或点击底部灵球区域。点击为桌面评审兜底，不代表正式游戏用点击代替拖动瞄准。

主线为：首页 → 加载 → 第一回合教学 → 第二回合 → 第三回合连锁 → 三选一 → 能力展示 → 再次弹射 → 通关。三个能力都已接入。下一关展示新的起始画面，未模拟第二关全部过程。

另有 13 个 Flow 可直接评审继续游戏、每周挑战、失败重试、好友榜边界和本地读写问题。异常入口不是游戏内新增的“调试菜单”。每个异常页均有返回或继续游戏路径。

## 动效

| 动效组 | 设计节奏 |
| --- | --- |
| 首页玉灵 | 约 4 秒轻浮动，不抢主行动 |
| 发射/碰撞/连锁 | 分段反弹、短促缩放和目标消散；页面之间采用短转场 |
| 奇遇面板 | 约 280 ms 上移进入，背景弱化，微信胶囊不被遮暗 |
| 分裂/回响/穿透 | 两球分离、邻近目标响应、穿透路径分别示意 |
| 最终清场 | 约 1.2 秒串联目标，完成信息在尾段出现 |
| 通关与奖励 | 分数短促出现，奖励稍后进入，不叠加大面积粒子 |
| 加载与榜单 | 进度推进；行项目约 60 ms 错峰进入 |

已写入原生关键帧的节点共 55 个，包含复用角色自带的轻浮动；并非 55 种独立动效。已将最终清场导出 MP4 并抽帧检查运动顺序和收束。导出器中的背景表现与 Figma 静态画面不一致，所以导出片仅用于运动诊断，不作为美术确认样片。其他简单动效通过关键帧参数和静态位置检查。

“减少动态效果”开关已有可切换的视觉状态，但未绑定全局时间轴。正式实现应移除装饰浮动、强缩放和震动，保留必要的轨迹、命中与状态提示。

## 轻量数据边界

章节、收藏、场景、设置和回合检查点仅本地保存；好友周榜是用户批准的唯一微信托管成绩例外，不创建自有账号、自建业务后端、云数据库、完整云存档或分析 SDK。

每周一北京时间 00:00 更新挑战与榜单周期。只比较同周同内容版本的个人最好成绩，同分并列，只展示平台可返回的同玩好友。重置本地进度和删除托管成绩是两个确认流程，不相互冒充。

画面里的姓名、分数、解锁结果、授权与同步结果均为示例。原型不会读取微信好友、上传成绩、删除真实数据或执行本地持久化；也未验证跨周进行中对局、设备时钟异常或离线重试的真实实现。读取失败的临时游玩不得覆盖原存档，是后续实现约束。
