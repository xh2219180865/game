# Project Context

## Purpose

“弹弹奇境”是面向中国大陆 18—40 岁休闲用户的竖屏微信小游戏。核心体验是一次瞄准触发整屏连锁，并在每三个回合进行一次弹珠能力三选一。

当前处于 Phase A：产品流程与 Figma 原型阶段。旧原生 Canvas 运行时已经永久删除，当前没有 Cocos Creator 工程。

## Planned Tech Stack

- 设计：独立 Figma 游戏文件
- 游戏引擎：Cocos Creator 2D，具体稳定版本在 Phase B 确认
- 语言：TypeScript
- 目标平台：微信小游戏
- 运行时数据：本地存储为主；好友周榜仅使用微信官方托管数据与开放数据域；不接自建后端、云开发数据库、完整云存档或第三方分析 SDK

## Project Conventions

### Architecture

- Figma 主流程通过验收后才允许创建 Cocos Creator 工程。
- 场景、节点、组件、Prefab 和配置表保持单一职责。
- 物理采用固定时间步，并使用子步进或连续碰撞检测保护高速小球。
- 发射队列使用游戏时钟，不使用大量 `setTimeout`。
- 关卡、砖块、能力和数值必须配置化。
- 每周挑战使用北京时间的周起始日与内置内容版本派生确定性随机种子，每周一 00:00 切换；仅切换本周挑战与好友榜周期，保留关卡、精灵、场景和设置。
- 进度、已解锁精灵/场景、设置和教学标记仅本地保存；本局恢复仅在明确的回合检查点进行。
- 好友周榜每人展示同周、同内容版本的最好成绩；只向微信托管周标识、内容版本与榜单必需成绩，不同步完整存档。授权拒绝、网络不可用或榜单失败不阻断游戏。

### Testing Strategy

- Phase A 验证用户流程、信息层级、单手操作、安全区和可读性。
- Phase B 验证弹射手感、碰撞正确性、等待时间、前后台恢复和中低端安卓性能。
- 正式配置通过自动模拟和真实玩家测试校准。

## Product Constraints

- 竖屏、单手操作，普通单关目标时长 1—3 分钟。
- 原型阶段不做实时多人、复杂排行榜、大型成就、完整商城、多币种、公会、聊天或 UGC。
- 原型阶段不接入插屏广告、Banner 或付费功能。
- 视觉采用“夜游奇境 · 国风霓虹弹射”：世界观保持治愈萌系与轻国潮，战斗场使用深靛夜色和玉色、鎏金、珊瑚高亮建立清晰刺激层级；不得退化为纯工业霓虹或传统广告大厅。
- 设计兼顾女性、非传统游戏用户、中年用户和中低端安卓设备。
- 不建立自有登录账号、世界排行、完整云同步或服务端奖励校验；只允许用户已确认的微信好友周榜作为联网数据例外。好友资料由微信开放数据域展示，不另建用户档案。
- Figma、Cocos 等制作工具不属于游戏运行时第三方服务依赖；微信平台自身运行和发布机制另行核对。
- 页面按看懂目标、完成第一发、理解反馈和直接重试验收；功能优先复用战斗状态与轻量弹层，避免增加导航负担。

## Compliance Context

设置中区分本地存档与微信好友周榜托管成绩：本地重置需确认，不得声称同时清除了云端榜单数据；提供平台允许的榜单数据清除路径。清理本地数据或换设备后不承诺恢复关卡与收藏。榜单入口说明微信托管数据用途，并处理平台所需授权；拒绝不影响核心游戏。正式发布时核对实际平台与隐私要求，不建立自建实名、账号、广告或付费服务。
