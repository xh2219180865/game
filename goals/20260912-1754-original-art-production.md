# 原创美术与剩余优化施工清单

目标：完成用户要求的剩余优化，将“设色山水、城关征战”的原创方向落实到正式地图、策略卡、对战效果和全部页面，并验证浏览器与微信构建。当前用户已授权实施，继续此前允许独立任务并行的偏好。

边界：不改七策效果、六图 42 节点、四兵种规则、数值、经济与存档语义；不启用储备、商业化、真人联机。不得提交、推送或发布。真机、平台服务和历史升级等条件的未验证项原样保留，不以本地替身验收。

## 目录与接口

- 新增 `assets/art/` 存放随两端构建发布的原创栅格素材及来源清单；不把完整概念页面作为可点击游戏背景。文件统一英文名称。
- `src/render/assets.ts` 负责平台无关资源注册、异步加载、裁切绘制及失败状态。平台入口提供 image 工厂；渲染代码不访问 DOM 或 wx。
- 公共接口（A 负责）：`drawArt(ctx, id, x, y, width, height, fit?: 'cover'|'contain'): boolean`；成功绘制返回 true，尚未可用返回 false。尺寸非法直接 false，保持 ctx 状态。`loadArt(createImage): Promise<void>`；图片使用本地相对地址，失败保留可重试状态，不能阻塞存档恢复或静默宣称加载成功。具体图片类型由 A 定义，浏览器与 wx 使用同一注册表。
- ID：`home`（home.jpg）；`terrain-plains`、`terrain-snow`、`terrain-desert`（同名 jpg）；`buildings`（buildings.png，4 列×3 行透明图集，列 barracks/archery/relay/fort，行 tier 1/2/3）；`cards`（cards.jpg，4 列×2 行图集，行序 mobilize/march/supply/feint/farming/logistics/fortification/空）。图集子项 ID 使用 `building-barracks-1` 至 `building-fort-3`、`card-mobilize` 等。七策按源图实际宽高等分；十二建筑使用实测源矩形（1448×1086 基准归一化），避免三级塔截顶；contain 默认保持比例。不透明原稿仅在 `.tmp/original-art/masters/` 留存，本轮以 JPEG quality 65 同尺寸编码后进入正式包；透明建筑保留 PNG。

## 并行任务

### A：资源管线（可立即开始）

目标：浏览器与微信可以从构建包加载同一套图片，加载慢／失败时规则和存档仍可用，可重试。
入口：scripts/build.mjs、scripts/dev.mjs、scripts/visual.mjs、scripts/runtime.mjs、src/platform/browser.ts、src/platform/wechat.ts、测试平台入口。
允许修改：上述平台和脚本、src/render/assets.ts、针对加载与包内容的测试。禁止修改 game.ts、art.ts、terrain.ts、核心规则、文档和图片。
接口按上一节；注册文件尚不存在时允许加载失败，主 Agent 制作素材后集成。检查 image factory 创建抛错、onerror、重复加载、部分成功、非有限绘制尺寸、图片未就绪；不引入第三方运行时依赖。
交付：改动文件、运行命令和结果、两端差异及尚未验证项。

### B：建筑美术（依赖 A 的约定接口，可并行制作）

目标：制作四类三级的原创透明建筑图集并接入 building()，四类必须在小尺寸可分辨，三级结构渐进，保留塔射瞄准与阵营旗／灰度识别。风格沿最新三屏概念：手绘有体积、汉末风格木石城寨、统一高视角和左上光，避免卡通几何色块与仙侠高楼。
入口：src/render/art.ts 的 building、现有渲染测试；参考生成图 /Users/xuhe/.codex/generated_images/01a08b3a-f48b-7c23-ba25-d055e32a4ee7/exec-066eb2d5-4f90-44e4-a862-11f76fa2d0c0.png。
允许修改：assets/art/buildings.png、src/render/art.ts 中 building() 及必要的资源导入、独立相关测试。禁止修改其它 art 导出、game.ts、管线、核心规则及文档。
素材通过 imagegen 技能生成，先读技能。保持每格完整、不串格、无旗色/文字/数字，实际旗与标签由代码绘制。drawArt 返回 false 时保留现有后备绘制。失败不可隐藏真实等级和塔箭方向。图集按实测独立源矩形裁切，不能等分截断三级塔。
验收：实际查看透明图集与小尺寸建筑样本，相关渲染测试。提交素材来源、最终提示词、尺寸、透明情况和风险给主 Agent。

### C：三种战场环境（依赖 A 约定接口，可并行制作）

目标：制作平原、雪地、大漠三种低干扰原创背景并接入 drawTerrain。背景不含可操作建筑、军队、数字、旗、UI、道路、横穿战场的河流/悬崖；装饰只在边缘，中央开放。保留地图真实据点位置与路线，背景不能替代规则。
入口：src/render/terrain.ts、src/core/maps.ts；同一概念图作风格参考。
允许修改：assets/art/terrain-plains.png、terrain-snow.png、terrain-desert.png、src/render/terrain.ts 和独立相关测试。禁止其它渲染文件、管线、核心及文档。
风格：偏俯视，矿物设色手绘地表、周边低矮林石，明亮清楚；不能照搬古稿或竞品。通过 imagegen 制作。六图按稳定 ID 分配环境，明确映射；无素材时后备可用。不要以地图矩形边框当世界场景。
验收：查看三张背景，小屏实际后续由主 Agent 集成；验证尺寸异常/ctx 恢复/确定性，交付来源、提示词和结果。
