# 战场体验优化施工清单

目标：优化实际验收发现的问题，形成符合已选“方案 A 青瓦城关”、适合竖屏单手操作的微信小游戏体验。审美验收依据用户明确偏好：国风建筑、清楚的地图和兵种等级、少说明、直接操作、有行军与交战反馈；不以自动测试代替玩家喜好或真机验收。

## 范围与不变量

- 完成攻城接触／冲击／换旗组合、随距离迈步、近身兵数牌、地图道路与营地融合、建筑等级尺度、暂停／升级／策略目标界面统一。
- 保持既有玩法、兵数、经济、道路连接、节点位置、实际旅时、射程、存档兼容与输入去重。美术不暗改规则。不扩展后端、联机、卡池，不提交或发布。
- 正式运行素材必须随包且微信目录不超过 4 MiB；不得依赖临时文件。
- 完成后执行 npm run check、320／375／430 页面与真实内存交互，检查减少动态、拥挤和失败保护。微信模拟器渲染、微信触摸、真机分别记录；自动化不能触发微信触摸时不可声称通过。

## 分工、接口与验收

### B1 行军与标牌（可并行）

- 背景入口：src/render/sample-sprite-regions.ts、battle-presentation.ts、army-pennant.ts；当前六帧按全局时间循环，标签可远离队首。
- 允许修改：sample-sprite-regions.ts、army-pennant.ts；battle-presentation.ts 仅 StableArmyLabels 类；tests/sample-sprites.test.ts、tests/stable-army-labels.test.ts 及独立标签测试。禁止修改 game.ts、core、文档、其他特效选择函数。
- 接口：保留 infantryWalkFrame；新增 infantryDistanceFrame(distance:number,slot:number,moving:boolean,phase?:number)，距离按规则地图单位传入，正常速度 24 时约 720 ms 一周期，兼行位移变化同步步频。无效距离／减少动态返回静止。
- 标牌优先贴队首侧上方；收紧最大关联距离，不覆盖营地驻军与其他队牌；极拥挤保留隐藏后的逐队查询。不要画横跨地图的连接线。
- 验收：距离、加速、错步、减少动态与无效输入；稳定放置、边界、不重叠和拥挤。交付改动、实际测试命令结果及限制。主 Agent 接入 game.ts 并看实际画面。

### B2 地表与建筑尺度（可并行）

- 背景入口：src/render/sample-ground.ts、art.ts、core/maps.ts。已选青瓦城关，当前营地像浮在地表，道路为粗直线。
- 允许修改：sample-ground.ts；art.ts 仅 building 的手绘素材尺寸／对齐分支；独立 ground／building 测试。禁止修改 game.ts、core、其他绘制函数、共享文档。
- 决策：不改地图位置或路网，不新增有玩法暗示的不可通行河流／关隘；在既有地面加自然边缘院落、城前铺地、中心广场，给道路接缝留白。三级步营保证一级可辨、二级有院墙、三级塔楼明显，避免只用同比放大。
- 接口：保留 drawSampleGround(ctx,b,point,scale) 与 building 调用签名。主 Agent 负责道路绘制与营旗位置集成。
- 验收：Canvas 状态恢复、无效输入、安全边界、既有建筑回退测试；主 Agent 实际看三尺寸。交付改动、测试与未验范围。

### B3 战斗与操作界面（主 Agent）

- 攻城保留接触特效，与换旗分阶段呈现，权属／兵数立即按规则结果显示。低动态保留静态命中，预算仍有界。
- 暂停以冻结战场＋紧凑弹层呈现；继续为主动作，设置／回首页为次动作，放弃保留明确独立入口，军情按需。退出临时练兵与存储故障路径不变。
- 城旁升级保留真实代价／留守／不足提示，减少装饰性文本负担；策略目标改贴地轮廓，卡面优先图形识别和可点面积。
- 负责 game.ts 与其余文件、设计文档、集成和全量检查。先修改对应规范再实现，不改子任务文件归属。

### B4 交互回归（与主 Agent 视觉验证并行）

- 允许修改 tests/view.test.ts 与 tests/quick-flow.test.ts，仅本轮暂停规格变化的用例及新增攻城组合／暂停输入保护回归。禁止修改实现及标签测试断言；行军两个失败由 B1 修复。
- 新规格：暂停展示原尺寸冻结战场，无背景交互；居中紧凑弹层，继续固定于弹层底部，关闭（back ID）也是明确继续；回首页／退出临时练兵使用 save-home，原始坏档保护不变。军情展开允许弹层内容滚动，主按钮不随滚动移动。主 Agent 实际画面检查后可能修复布局，但以上行为不变。
- 新增成功攻城真实事件回归：有效敌方 arrival 与 capture 同刻，权属／兵数立即更新且成功夺城仍绘制钢刃接触（stroke #F9EBCB）；0／180／550／800 ms 和减少动态检查，错误友援不画交战，渲染不得改数据。
- 不因检查失败弱化状态、存储、输入或真值断言；旧缩略图尺寸断言改为新原尺寸背景与不穿透验证。报告确实变化的预期、专项结果及发现的实现问题。
