# v1.3 附录 F：合理性、难点与后续验证

更新：2026-09-09。本文区分“已经做出的设计决定”“纸面推导”“尚需实测的假设”。不宣称留存、胜率、性能或美术吸引力已验证。

## F1. 本轮主动修正及理由

| 原问题 | 本轮决定 | 收益与代价 |
| --- | --- | --- |
| 系统多、首页散，双人容易刷卡 | 只保留正式四方；练兵独立不发卡 | 主循环清晰，但首胜必须验证可达 |
| 批前最后城失守，即使同时有新城仍死 | 按同批全部结算后实际城数淘汰 | 与画面一致；同刻互换城继续，非同刻仍先失守者败 |
| 无限僵持，不适合碎片时间 | 240秒截止，城数→兵力，同值并列 | 时间可预计；必须防守最后城，也有后段争城冲刺 |
| 最快数百毫秒到达很难回防 | 基础80，最短1000ms，整体最高160 | 留反应窗口；极短路线兼行可能无收益，比较整数ETA，整次取消不扣卡/兵 |
| 胜利后还有隐形亲手夺城条件 | 标准独立冠军即胜场（仍须有效派兵） | 规则一致，不用“赢了不给奖”惩罚防守 |
| 初次被动很晚，早周无构筑体验 | 1/4/8胜各一次，不赠卡 | 首次标准胜即可选打法，再需3/4胜；仍总三次 |
| 主动太舍不得用 | 冠军一次三选一、同种得2张 | 首次可尝试一次留一次；不放宽独胜资格，需观察囤积 |
| 失败也升军衔，缺少胜负意义 | 胜+30，第2/3/4扣5/8/10，0下限、可降衔 | 一胜抵最多三次末名扣分；有进取感也有损失压力，保留历史最高纪念 |
| 无卡玩家对每电脑两张攻击/防守卡 | 每电脑仅征召乡勇1、零被动 | 无瞬时AI倍道兼行突袭；仍须实测新手难度 |
| 用卡已扣、杀进程却整局丢失 | 消费与完整战场同事务，普通5秒检查点 | 提升可信感，增加本地事务与恢复测试成本 |
| 好友榜只是“以后再定” | 比本周标准冠军次数，官方范围，同分并列 | 不增加玩法复杂度，但不能防本地篡改/保证跨设备合并 |
| 主题空泛或接近参考水墨 | 彩绘军棋沙盘，形状＋颜色，正文与战场优先 | 原创方向具体，但真实审美必须后续出图/试玩验收 |

保留用户要求：三国八军衔多级、军功胜加败扣、主动有库存即可反复用、被动当周每局自动且重复增强、本地核心和官方好友榜例外。没有用“平衡”名义暗改成两槽/每卡一次。

## F2. 城池与兵种的取舍

兵营产能高，驿站从源头提速，堡垒容量大；不是攻击/防御/骑兵三种兵种。把所有战斗兵统一成军士，玩家只比较兵数，战略深度来自目的地、时间、调援与策略。

堡垒价值成立的条件是多路援兵能集中，不能只看其空城产速。堡垒I容量80比兵营I多30，但每秒少产0.5；若只是单点等兵，60秒才追平30兵容量差，且通常先受容量上限影响。这说明堡垒必须在地图/AI中出现接援用途，不能声称它天然更强。

驿站I路长200：普通2.5秒、驿站约1.852秒，省约0.648秒；经过驿站要两次派兵，且每次派半数，不保证任何路线中转都更好。只有作为前线集结、持续产兵或回防出发点时更有价值；文案不用“必经加速站”。

容量层数+15不是马上+15兵，产速+15%也不是开局多15%，所以初始表必须保持不变。等级II是地图资产差异，不是军衔/兵法层数或第二兵种。

## F3. 奖励与军功纸面账

以下是新基线的可计算推导，不是玩家实测或付费/留存预测。

| 周内有效冠军次数 | 累计主动选择 | 全部领取的主动总张数 | 累计被动机会 | 说明 |
| --- | ---: | ---: | ---: | --- |
| 0 | 0 | 0 | 0 | 无卡照常玩；没有参与卡/失败晋升 |
| 1 | 1 | 2 | 1 | 一次选同名2张；第一份周打法 |
| 4 | 4 | 8 | 2 | 第二份需再赢3局 |
| 8 | 8 | 16 | 3 | 第三份需再赢4局 |
| 9 | 9 | 18 | 3 | 继续主动奖励，不再增被动 |
| 12 | 12 | 24 | 3 | 无第四次被动/周保底 |

张数是领取总量，不是扣除消费后的剩余库存；机会不等于已领取。首胜要依次处理主动、被动两个选择，但军功只计一次，允许稍后，不叠加图鉴/全屏升官教学。

| 假设每局独胜率p | 达1/4/8胜的期望局数 | 平均每局新获主动张数2p | 前5局仍无胜的概率 |
| --- | --- | --- | --- |
| 25% | 4 / 16 / 32 | 0.50 | 23.73% |
| 40% | 2.5 / 10 / 20 | 0.80 | 7.78% |
| 50% | 2 / 8 / 16 | 1.00 | 3.13% |

假设各局独立且胜率固定，期望为w/p，概率为(1−p)^5；实际学习/构筑/电脑会改变胜率，不能据此承诺时长。以25%且每局都打满4分钟计算，1/4/8胜约16/64/128游戏分钟，现实另含菜单；普通用户无需满层也应体验完整。主动“本局不限用”是库存足够就能用，不是每局免费无限产卡。旧每胜1张改2张仍不保证低胜率玩家每局有卡。

### F3.1 胜负军功是否更合适

比每局参与就升级，更符合用户希望的胜负意义，也让争取第二名而非早退有价值；代价是从轻松履历转向有损失的成长。军功不加战斗属性/卡奖励、不用于匹配，避免输分又削弱战力的双重惩罚。

应计军功为第1/2/3/4：+30/−5/−8/−10，平列第一0，弃战−10，实际遵守0下限。一次胜利的+30等于三次第4的最大扣分；不存在连败加罚或保级广告。教程与练习不计分且可反复练手。

- 若四个名次各25%，远离0下限的每局期望变化=(30−5−8−10)/4=+1.75军功，约17.14局/30分只是平均量级，不是晋级所需局数承诺。
- 若胜率40%，其余三名在败局中等概率，则期望30×0.4−(23/3)×0.6=+7.4；约4.05局/30分。
- 若每次失败都第4，期望40p−10，胜率低于25%时会长期趋近低分段。0下限防负债，不能自动解决新手挫败。
- P=30第一次授军司马后一次第4可能回20/新卒；这是当前允许降衔的明确后果，不暗设军职永久保底。用历史最高纪念与免费练兵缓和，并专门观察刚晋升就降级的体验；若多数人因此不愿再战，需再提规则调整，不能宣传必然更留人。

失败不倒扣本周胜场、策略库存和被动层数；周重置只清周资源，军功与最高记录不重置。榜单仍比对电脑周冠军次数，军功不是具有反作弊保障的真人竞技评分。

### F3.2 卡片必须改变选择，不只是增加数值

基础50%保留：抢产兵营、抓敌城出兵后的空虚、调援守末城，三种抉择都不用卡。40兵连续两次普通派兵可送20+10=30（75%），金蝉单次80%送32；仅为多2兵/少一次手势付稀缺库存，价值尚不充分。它后移，不为了已写设计就优先开发。

四主动的可读用途是：鸣鼓征兵为下一波扩张攒兵；乡勇应对当刻缺兵；兼行争到达先后（无省时不花卡）；火袭压敌方未来新生守军。按基础产速0.5—1.5估算，3秒火袭少产1.5—4.5兵的连续值，整数结果还受生产额度/容量/其它效果影响，不是扣除现有守军。是否真形成进攻窗口必须测。

### F3.3 尚未启用的对照试验方案

每次只改变一项，在单独无奖励测试会话中给明确测试库存/层数；不消耗/赠送正式资产，不计军功/周胜，不上传榜。测试顺序交替，同地图/电脑/初始状态；重复同局会有学习偏差，须另用相同规则的局面交叉复核。这里完成的是设计，不是已获授权制作或执行实验。

| 顺序 | 对照 | 观察与停止条件 |
| --- | --- | --- |
| 1 | 不给任何卡的50%基础版 | 玩家能否讲清一次抢产能/趁虚攻击/调援的取舍，且自愿再开；基础不成立先改节奏/反馈，不靠堆卡 |
| 2（有操作痛点才做） | 50%单手势 vs 免费可选80%重兵派遣（非付费卡） | 统计同源同目标短时间重复拖拽、误派/留守不足与操作理解；只有明显减少重复且未增加误操作才评审引入，当前仍50% |
| 3 | 火袭3秒 vs 5秒，仅改持续时间及相应续时 | 记录实际少产、是否改变某波攻城/救援的结果、玩家是否能解释收益；若5秒也无法形成可读决定，重新审视效果而非继续拉长；正式仍3秒 |
| 4 | 扩营增垒 vs 新城招抚作为第三被动，分别测1层及3层边界 | 同样只有三个被动种类/最多三层；比较可感知收益、选后愿否再玩、领先方滚雪球。招抚不是直接加进第四被动，也不因此多给机会 |

“整军振旅”目前没有玩家可解除的常规负面来源：标准电脑只有乡勇。暂缓，不为让卡有用就暗给电脑火袭/缓兵；未来独立批准电脑负面策略与公开决策之后，才一起验证反制。其它储备见H。

囤卡/被动滚雪球、到期损失感仍是风险。先验证真实效果、地图/电脑节奏和解释，再提有证据的数值调整；不暗加用卡上限/共享冷却、不发保级卡或接支付广告。

## F4. 高频难点与设计防线

| 风险 | 必须防线 | 后续观察点 |
| --- | --- | --- |
| 最后城秒丢挫败 | 一秒最短路、固定AI初动、可见军团/ETA、末城局部预警 | 玩家能否提前发现与执行回防 |
| 半数派兵不够精细 | 松手预览派出/留守/ETA；F3.3按需比较免费重兵，当前不改 | 重复拖拽与误以为全军出击的比例 |
| 截止前刷出兵改变总兵 | 在途与驻军总和一起比较，等量转移不改变分数 | 边界到达只计算一次 |
| 守城等电脑互攻获胜 | 正式独胜仍奖励，地图争城与倒计时鼓励行动 | 是否存在机械稳赢路线 |
| 多方同时到达难懂 | 同刻来敌先抵消，查询显示阵营与ETA；不并电脑阵营 | 理解困难时优先改说明，不随机判胜 |
| 重复主动续时浪费 | 预览新增时长与实际补兵，取消无消耗，胜负先于输入 | 高频误用/投诉，不藏倒计时 |
| 被动让局面改变 | 所有有效属性可查，开局/新夺城统一快照 | 三层与无卡都应可正常完成 |
| 跨周丢卡/旧局利用 | 日期明确、事务接受时归周、24小时单局收尾、旧待领不挪周 | 23:59到00:01及暂停恢复 |
| 中断/双回调重复奖励 | revision、matchId/actionId/choiceId、原子经济＋快照 | 每个提交点杀进程/重复回调 |
| 好友榜隐私或身份误解 | 开放数据域隔离、明确电脑对局、本机与托管分开、可停止/删本人 | 授权拒绝/换机/空榜/跨周 |
| 卡顿遮数字 | 限制表现，不删规则事件；先降粒子/尾迹 | 低端机大量军团/连点策略 |

## F5. 性能与制作预算

这些是实现验收目标，不是平台硬限额或当前性能结果。

- 实机以稳定30fps为最低目标、能力足够60fps；同输入30/60fps结果完全一致。
- 触摸到可见选中/路线反馈目标p95≤100ms；正常本地事务提交目标p95≤100ms，超过150ms有保存状态，失败保护暂停。
- 逻辑兵团不建逐兵刚体；先用256同时在途兵团、9城、频繁策略与同时到达做压力用例。256是测试规模，不是玩家出兵硬上限。
- 表现预算：每团最多5军士，拥挤时降为1旗＋数量；全场同时短粒子≤80、声音≤4，先合并视觉/音效不丢伤害或输入。
- 单个序列化存档槽目标≤256KiB、双槽合计≤512KiB；超出时先精简字段/失效实体，不截断合法库存/兵团。必须核对平台真实存储限额。
- 首屏自有美术与音频资源预算≤3MiB（不含引擎）；总首包仍须按实际微信限制检查。冷启动可操作目标≤5秒需记录机型/网络，资源齐备后的回流目标≤2秒。
- 连续20局结果/快照/粒子/音频资源可释放，内存应无单调持续上涨；后台无战斗模拟与音频播放，不轮询榜单。
- 不引入3D、骨骼武将、独立三兵种动作库、大中文字体下载或第三方分析来追求表面完整度。原创资产最小清单见B9，每项记录来源、作者、许可及修改范围。

## F6. 未来试玩验收方案

先完成规则自动化与恢复用例，再做新手与复玩体验。建议5名未读文档者各首玩10分钟，另3名完成至少20场标准四方，对比无卡、单被动和三层构筑；小样本只是发现问题，不足证明市场留存。可由开发者手工记录匿名测试编号，不收微信身份/安装统计SDK。

| 观察项 | 首轮准入目标 | 不通过的优先处理 |
| --- | --- | --- |
| 基础理解 | 至少4/5人在无口头指导下完成首次派兵并能解释半数派兵 | 调整引导/预览，不加长开场文档 |
| 胜负理解 | 至少4/5能解释最后城、四分钟城数优先 | 改规则短文案/末城与时间提示 |
| 首胜可达 | 大多数新手在正式前5局内有独胜；记录实际分布 | 调AI安全余量/初动/地图，不发隐藏免费卡 |
| 决策变化 | 每图至少两种扩张路线被主动采用，不总是机械等待 | 调资源位置/守军/AI，不加大量额外系统 |
| 用卡理解 | 能区分选一种得2张/每用扣1与被动不扣层；用后能解释改变了什么 | 调预览；无效果卡后移，按F3.3对照，不把特效好看当收益 |
| 胜负成长 | 能复述胜加败扣/并列0/0下限，区分当前与历史最高；记录刚升衔又降级是否放弃再战 | 先修解释与新手胜负体验，再评审评分，不暗改积分/发保级卡 |
| 放弃与中断 | 无“以为回首页会判负/用了卡却无法恢复”的误解 | 修复措辞与事务一致性 |
| 审美与可读性 | 三种屏幕下数字/按钮无遮挡，用户能指出主动作与己方城 | 去装饰/增对比/调整布局，不能靠截图自评通过 |
| 再玩动机 | 询问为何再开/不再开，记录决策、成长或疲劳原因 | 基于原因改核心节奏，不能宣称“用户一定喜欢” |

## F7. 变更和冻结

本轮不再留下“计分/主题/奖励/恢复以后再决定”这种核心设计空白。保留的未知仅为实施时的引擎版本、平台实时政策与真实体验/性能结果，它们有E8、F6和C的明确检查路径。

之后若改地图/AI/奖励/战斗数值影响计奖公平，增加rulesetId并在新自然周启用；纯错字/不改规则的美术修正只升contentVersion。同一周不能把不同规则成绩混榜或用新规则强行读旧局。紧急修复无法兼容旧局时保留存档并说明，不偷偷重算输赢。

未发布现阶段可以在本提案内修订；正式上线后规则变更需新OpenSpec提案和存档兼容检验。文档通过后再经用户授权做原型/代码，当前不越过边界。
