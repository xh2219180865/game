## B1. 全部页面与回路

全局：同一时刻一个主页面＋至多一个模态；错误/平台必须事项优先。返回关闭当前浮层回来源页，不串跳首页。战斗中打开设置先进入暂停；用户必须明确继续才推进游戏。

## B2. 首页和首次/回流流程

### B2.1 首页层级

顶部：工作名“四方夺城”、小军旗名片“军司马 · 二级”、设置入口，避开微信胶囊。中部：一幅低对比军棋沙盘小景，不放可以误触的假城池；一句“拖出一半兵，四方争一胜”。主按钮一枚，次入口分为“练兵”“本周策略”“好友周榜”，军衔名片本身可点。

周进度为一条安静的信息区：如“本周1胜 · 再胜3局可选兵法”，详情展开1/4/8标记；到8胜后写“本周兵法已全部取得机会”，不显示停滞经验条。无待领不挂常亮红点，无卡也不显示缺资源警告。

### B2.2 主动作优先级

1. 存档/事务不确定：先S07，“恢复存档”，不能开始正式局覆盖。
2. 已保存未确认结果：S04，“查看上局结果”；确认过结果但尚有选择时主按钮“领取策略”，到S09。
3. 有可恢复战斗：“继续对战”，到S03；不进新准备页。
4. L01未首胜：“开始练兵”，到L01。
5. 其余：“四方夺城”，到S08。

上述是首屏/主按钮规则，不禁止用户查看设置/规则/榜单；待处理结果或续战期间进入无奖励练兵前提示其不覆盖正式存档，使用独立临时练习会话。平台必须同意项按平台实际要求处理；不假定无需任何合规提示。

### B2.3 三条闭环

- 新用户：资源可用 → 首页 → L01首次引导 → 首胜结果/解锁正式与L02（军功不变） → 建议下一课，次动作“进入四方” → S08 → 正式局。
- 老用户：读档/切周 → 首页 → S08（默认总是展示，可快速确认，不做再增加一层确认）→ 对战 → 结果 → 有奖依次主动/被动选择 → 保存反馈 → 再战准备。
- 中断用户：后台停战/存检查点 → 回前台S03 → 明确继续原局；冷启动有效快照同样恢复，结果已保存则去结果而非重算。过期/不兼容快照进入S07：兼容过期正式局确认弃战才扣10，取消不能另开正式；技术故障按E恢复或技术作废，不静默认输。

## B3. 小屏战场布局

基准375×812，必须另验320×568与430×932。全部使用屏幕逻辑尺寸；微信安全区/胶囊按实际测量，不画假胶囊。

上区：安全区后48高内放暂停、我的城数/存活方数和倒计时；余量不足时阵营小旗与计时拆成两行，不能重叠系统控件。四方显示“03:12”“我方2城 · 剩3方”，不常驻总战力/军衔/金币。

下区：安全区前至少112高，第一行4个主动按钮各至少44×44，有名称短词和库存；第二行提示/可折叠被动状态。详情展开占用该提示区，长说明进入暂停后的规则页，不盖地图。教学下区只用提示，不显示七张陌生卡。

战场占剩余区域，比例360:540，缩放k=min(可用宽/360,可用高/540)，居中不裁城。触控目标独立扩为44×44，兵数16、辅助13、正文15—16不随k无限缩小。小屏先省小景/装饰/长说明，再缩战场；关键触控不重叠才通过。

例：320×568，预留顶部72、下部128（包含本例安全留白），余高368，k≈0.6815；最小城距105映射约71.6，大于44。仅说明布局可行，不替代不同实际胶囊/安全区检验。若实际可用区无法满足触控，显示“请竖屏使用/调整窗口”，暂停，不裁掉功能。

## B4. 原创视觉规范

时代：汉末三国·群雄军阵。方向：轻国风彩绘军棋沙盘。2D正视可读城池＋少量斜面，简洁木质边缘与布旗；不使用写实战争血腥或复杂武将立绘。三个地图共用基础美术，只用小标题/局部低对比点缀区分资源布局，不加装饰碰撞。

| Token | 颜色 | 使用与前景 |
| --- | --- | --- |
| paper | #F3E8D4 | 暖浅底；正文用ink |
| ink | #253B45 | 正文/数字/轮廓 |
| player | #176D70 | 玩家青色，白字，菱形旗 |
| enemy1 | #B13D36 | 电脑甲朱色，白字，三角旗 |
| enemy2 | #C99A32 | 电脑乙金色，ink字，圆旗；禁止白字 |
| enemy3 | #5F579C | 电脑丙紫色，白字，方旗 |
| neutral | #D8D0C2 | 中立，ink字，空心旗 |
| surface | #FFFDF7 | 面板，ink字；不使用半透明纹理压正文 |

阵营名：你＝青旗军；电脑甲＝赤旗军、电脑乙＝金旗军、电脑丙＝紫旗军，标签保留“电脑”。它们是架空演练军阵，不声称史实国号、旗色或真实玩家。军帐/木栅/土石城/路亭点缀服务汉末军阵感，不添功能建筑或兵种。

颜色仅区分归属，类型靠轮廓（兵营营帐/堡垒墙垛/驿站路标），等级I/II固定小标。敌人也带“电脑甲/乙/丙”说明，不伪造真人头像。玩家旗始终菱形，色觉差异下仍能认。

普通中文用平台可用清晰无衬线字体，标题用同族较粗字重；不依赖大体积自定义书法字库。若定制logo仅独立字标，不替换游戏数字字体；素材授权记录见F。数字等宽，不能让999→1000横向跳动影响按钮。

间距基于4/8/12/16/24，页面左右16（小屏12）；控件圆角12、面板16。阴影至多一层弱接触影，无玻璃霓虹/连续流光。对比计算基线：paper/ink约9.67:1；青/朱/紫白字均大于5.8:1；金底ink约4.55:1，中立ink约7.66:1。不可把这些色值随意加透明度后沿用对比结论，真图需重测。

## B5. 城池、军士与战斗状态

城池四信息层：类型剪影 → 阵营旗 → 实际驻军数（城内字号最大） → I/II。容量只在查询/满仓时提示，不把每城都画成血条HUD。最后城显示一个稳定标记，收到已出发来袭后局部强调；不画全图防御范围。

| 状态 | 呈现 | 输入/退出 |
| --- | --- | --- |
| 首次教学 | 单条手势与“拖到这里，派出一半兵力” | 整个模拟冻结，只接指定第一次派兵 |
| 按住源点 | 选中描边、派出X/留守Y | 兵数随状态更新；轻点转查询 |
| 有效拖拽 | 单条路线、预计ETA、目的旗 | 松手成功；非保证攻占 |
| 无效拖拽 | 撤掉目标高亮、必要短原因 | 取消不扣；源易主立即清预览 |
| 行军 | 少量军士、阵营旗、实际数量 | 不等动画结束可继续派兵 |
| 到达 | 数字立即更新，短增减反馈 | 逻辑先结算，不串行等待多个特效 |
| 夺城 | 旗帜切换与轮廓换色 | 城已归新主即可操作，不被占领动画锁住 |
| 最后一城 | 稳定标记；受袭再局部强调 | 仍可调兵/征召乡勇，不提供临时免死 |
| 最后30秒 | 一次“到时城多者胜；同城数比兵力” | 不改变规则、不加速模拟 |
| 终局 | 冻结，取消未提交动作 | 正常保存完成后600ms内结果主动作可用；保存异常转恢复，不伪造可领取 |

行军不是敌军进入“城圈”就提前伤害；路过城市不交战。装饰小兵数量不等于兵团实际数量，标签一直可查。拥挤时合并视觉尾迹但不能合并不同规则到达事件。

## B6. 主动、被动与选择的具体手势

四主动始终在底部，依次用G2两字短标“征兵/兼行/乡勇/火袭”；详情、选策和策略库用四字全名，避免小屏挤四个长名称。点卡只进入待施放，不扣张；点有效城确认鸣鼓征兵/征召乡勇/火袭粮营，倍道兼行要求接着完成一次有实际ETA收益的合法拖拽派兵。点空白、再点已选卡、返回/暂停/后台取消；切换另一张卡取消旧准备。源易主或到期不“自动帮玩家换目标”。

待施放时底部显示成本/实际作用，“征召乡勇+2（容量限制）”“鸣鼓征兵5秒→13秒，消耗1”；同名续时不是×4。短按确认后不再叠加第三次确认；用户已从预览知晓成本。保存成功即更新库存、效果与战场；动画不锁下一次合法用策。同手势不重复消费，不同手势可以连续用完库存。兼行预览“普通2.50秒 → 加急1.67秒”；若两者整数毫秒相同则显示“此路线无需加急”，松手整次取消，不扣卡/兵、不建队，仍可另选路线或显式取消兼行后普通派兵。精确校验用整数毫秒，不用两位小数显示值。

耗尽态仍可点看说明“获胜可选择”，不可弹商店。满仓等无效目标有原因且不扣；所有城均无效时提示“当前没有有效目标”，可取消。周到期即时更新灰态，不能播放技能但不生效。

被动为状态不是释放按钮：如“屯田Ⅱ · 产兵+10%”，点详情明确“本周每局自动，不消耗”；开局一次轻显后收纳。跨周旧局注明“仅本局继续生效”。策略库分“主动锦囊/被动兵法”，层数不写成“剩余2张”。

S09三候选纵向卡适配小屏（无需横向挤三列），每卡名称、效果一句、现有→获得后、到期；主动写“选一种，得2张”（例如2→4），被动写“选一种，增强1层”（例如1→2）；不靠稀有度金光诱导。选中描边并启用确认，确认成功后依次进入剩余奖励；无剩余回结果摘要。稍后/放弃路径见D2。

## B7. 结果、周榜和异常文案

| 情况 | 标题/解释 | 主动作 |
| --- | --- | --- |
| 独立胜出 | “本局胜出”；全场仅你存活或到时城市/兵力领先 | 选择策略 |
| 最后城失守 | “本局第N名”；“最后一城被攻占，在途军士撤离” | 再战；次动作练兵 |
| 到时落后 | “本局第N名”；列各方已确定城数/兵力 | 再战 |

| 周榜暂无记录 | “本周还没有可显示的好友成绩” | 去对战；不伪造机器人榜 |
| 上传失败 | “本地已保存，好友榜暂未更新” | 可重试，不阻断再战 |
| 本地保存不确定 | “正在恢复本局记录，请勿重复领取” | 重试/无奖励练兵 |

周更替首页一次摘要“本周重新出发，军功与历史最高不重置”；战内只非模态提示库存到期，避免挡住派兵。设置清本地与删除本人托管分别确认，实际失败不能显示删除成功。

## B8. 动效、声音与减少动态

下表约束通用时长；逐卡视觉符号/分镜、出兵全过程和并发优先级以G4—G6为专项补充，不能用同一个光圈替代全部效果。逻辑数值与有效归属始终立即正确，保存未明确成功时不播成功施策。

| 事件 | 时长基线 | 表现与约束 |
| --- | --- | --- |
| 按下/选中 | 60—100ms | 描边或≤3%缩放，不移动触控区 |
| 路线变化 | ≤80ms | 跟手单线，禁止惯性追赶 |
| 派兵 | 100—180ms | 源点轻反馈，队伍立刻出现；不延迟扣兵 |
| 到达/兵数变化 | 100—160ms | 数字立即更新，短小增减；不慢慢滚真实兵数 |
| 夺城 | 220—320ms | 旗切换与短色彩过渡，不全屏文字 |
| 最后城受袭 | 200—350ms | 局部提示；同城3秒内不重复强提醒 |
| 主动施放/续时 | 150—250/100—180ms | 作用目标小图标；续时标+8秒/+3秒 |
| 被动开局生效 | 150—250ms | 最多3个小图标轻显，不逐张仪式 |
| 选策入库/强化 | 180—300ms | 保存后变化，数量/层数分别表示 |
| 军功/军衔变化 | 升级200—350ms；扣分/降级100—160ms | 数值一次即时更新；跨衔上升短换旗，下降克制说明，历史最高可查；不挡再战 |
| 页面/暂停弹层 | 150—220ms | 简单淡入，战斗先暂停 |
| 正常终局到可操作 | ≤600ms | 以结算已一致提交为前提；保存异常显示恢复状态，不放行不确定奖励 |
